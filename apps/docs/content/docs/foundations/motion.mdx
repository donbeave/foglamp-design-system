---
title: Motion and accessibility
description: Preserve interaction states and respect reduced motion.
---

Foglamp uses CSS transitions, animation utilities, and Motion for interactions and illustrative components. Menus and popovers, for example, use open and closed state animations. Preserve the original timing and state classes when extracting a component so that the animation remains tied to its interaction.

The effects stylesheet and HUD styles include `prefers-reduced-motion` rules. Test motion in both preference modes and keep content and controls usable when animation is reduced. Do not rely on motion alone to communicate a state.

Keep visible keyboard focus, accessible names, and the semantic props supplied by Base UI. Test composed controls with a keyboard as well as a pointer, especially when using the `render` prop or a router link adapter.
