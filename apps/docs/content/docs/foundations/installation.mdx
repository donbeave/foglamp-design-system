---
title: Installation and usage
description: Run the workspace and use Framerock components via package imports or the shadcn registry.
---

The repository uses Bun and workspace packages. From the repository root, install dependencies and start the docs portal:

```sh
bun install
bun run dev
```

The docs app runs on port 3000. Open `/docs` on the local server. To run the workspace type and unit checks, use:

```sh
bun run check-types
bun run test
```

Import components directly by package subpath:

```tsx
import { Button } from '@tailrocks/framerock/ui/button';

export function Example() {
  return <Button>Save changes</Button>;
}
```

The consuming app must process the package's Tailwind classes and load its styles. Import `@tailrocks/framerock/styles/globals.css` and `@tailrocks/framerock/styles/effects.css`, and include `@tailrocks/framerock` in your Tailwind `@source` scan alongside the fonts described in [typography and icons](/docs/foundations/typography).

### TypeScript configuration

Copied registry components and `@tailrocks/framerock` package imports compile cleanly under both default TypeScript (`tsc --noEmit`) and strict TypeScript (`"strict": true`):

```json
{
  "compilerOptions": {
    "strict": true,
    "jsx": "react-jsx",
    "module": "ESNext",
    "moduleResolution": "Bundler",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

## Install from the registry

To copy components into a consumer project using the `shadcn` CLI, configure your `@/*` path alias to point to `src/*` and install the global stylesheet and desired components:

```sh
npx shadcn@latest add http://localhost:3000/r/style-globals.json http://localhost:3000/r/ui-button.json
```

Import the installed stylesheet once in your application entry point:

```ts
import '@/components/framerock/styles/globals.css';
```

The stylesheet imports `effects.css` and `font-setup.css`, which configure the variable Inter, Host Grotesk, and Geist Mono font faces and Tailwind v4 theme tokens.

The button component is installed at `src/components/framerock/ui/button.tsx`. Import it using your configured alias:

```ts
import { Button } from '@/components/framerock/ui/button';
```
