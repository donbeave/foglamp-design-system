---
title: Geometry and controls
description: Squircle corners, dual-mode forms, and drawer buttons.
---

Framerock combines a rounded fallback with progressive squircle corners. Classes such as `rounded-md squircle:rounded-2xl corner-squircle` retain a rounded shape where corner shapes are unavailable and apply the squircle treatment where supported. The `@toolwind/corner-shape` plugin provides the `squircle:` variant. Keep the fallback and variant together.

Inputs, textareas, and selects share the form language but have distinct light and dark treatments. Light controls use `--custom-shadow`; dark controls use borders and a translucent input background. Focus rings, invalid states, and disabled states carry meaning in both modes. Preserve these states when composing a field.

Drawer actions use `DRAWER_BUTTON_CLASS` from `@tailrocks/framerock/ui/button-styles`. It includes the light outline shadow and the dark secondary treatment. Reuse the class for actions that need the same drawer appearance.

Base UI's `render` prop changes the rendered element while keeping a control's behavior. Pass the supplied props through to the rendered element and keep its accessible name and keyboard behavior intact.
