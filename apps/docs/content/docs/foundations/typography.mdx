---
title: Typography and icons
description: Fonts and icon choices in Framerock.
---

The docs portal loads the packaged Inter variable font and its italic face for text. It also loads Geist Mono and Host Grotesk variable fonts. The portal defines `--font-sans`, `--font-geist-mono`, and `--font-host-grotesk` in its app stylesheet. Consumers need to load the faces and define the font variables their chosen components use.

Framerock uses `@tabler/icons-react` throughout its interface. Some designs use the `Filled` icon variants. Preserve the selected icon variant, size, and color when reproducing a component, because a filled icon and its outline counterpart do not have the same visual weight.
