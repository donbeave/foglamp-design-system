---
title: Package architecture
description: How the Framerock package fits into an application.
---

`@tailrocks/framerock` contains UI controls, widgets, charts, blocks, styles, assets, and supporting utilities. Import the part you need through its package subpath. For example, the button is available at `@tailrocks/framerock/ui/button`.

The package separates presentation from application routing. `FramerockLink` renders a native anchor by default. Wrap your application tree in `FramerockLinkProvider` with a router link component to integrate client-side navigation (`FoglampLink` and `FoglampLinkProvider` remain exported as 1:1 compatibility aliases).

```tsx
import type { ComponentPropsWithoutRef, ReactNode } from 'react';
import {
  FramerockLink,
  FramerockLinkProvider,
} from '@tailrocks/framerock/lib/link-context';

function RouterLink(props: ComponentPropsWithoutRef<'a'>) {
  return <a {...props} />;
}

export function AppProviders({ children }: { children: ReactNode }) {
  return (
    <FramerockLinkProvider component={RouterLink}>
      {children}
    </FramerockLinkProvider>
  );
}
```

Base UI controls support composition through their `render` prop. Use it when a control needs to render another element, and preserve the props and ref that Base UI supplies so focus and keyboard interactions remain intact.
