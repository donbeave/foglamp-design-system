## Public API

The table lists public exports used by this story. Prop names and TypeScript types come from the design-system source.

| Export | Prop | Type | Meaning |
| :--- | :--- | :--- | :--- |
| `CostBreakdownView` | `data` | `readonly CostBreakdownRow[]` | Rows consumed by the component or visualization. |
|  | `range` | `RangeValue` | Resolved reporting interval used by the view. |
|  | `isLoading` | `boolean \| undefined` | Shows the component loading state. |
|  | `isUpdating` | `boolean \| undefined` | Marks data as refreshing while the current view remains visible. |
|  | `title` | `string \| undefined` | Sets the component heading or SVG title. |
|  | `className` | `string \| undefined` | Adds a class to the rendered root element. |
|  | `syncId` | `string \| undefined` | Recharts sync group ID for synchronized charts. |
|  | `onZoomSelect` | `ZoomSelectHandler \| undefined` | Receives x-axis endpoint values after a drag. |
|  | `onZoomReset` | `(() => void) \| undefined` | Runs when the zoom selection resets. |
| `resolvePreset` | `key` | `string` | Argument accepted by resolvePreset. |

## Requirements

Pass a resolved range from `@foglamp/design-system/lib/range` as `range`. The view receives data through `data`; `isUpdating` marks a refresh while existing values remain visible.
