## Public API

| Export | Prop | Type | Description |
| :--- | :--- | :--- | :--- |
| `RangePicker` | `value` | `RangeValue` | Active preset or custom absolute date-time range. |
| | `onChange` | `(next: RangeValue) => void` | Callback fired when the user selects a preset or applies a custom range. |
| | `compact?` | `boolean` | Renders a compact trigger button suited for dense toolbars. |
| | `className?` | `string` | CSS class applied to the trigger button. |



## Requirements

`RangePicker` reads and updates shared range state. Render it under `RangeProvider` from `@tailrocks/framerock/widgets/range-context`.

## Usage

```tsx
import { useState } from "react";
import { RangePicker } from "@tailrocks/framerock/widgets/range-picker";
import { resolvePreset } from "@tailrocks/framerock/lib/range";

export function RangePickerExample({
  compact = false,
}: {
  compact?: boolean;
} = {}) {
  const [range, setRange] = useState(() => resolvePreset('7d'));
  return (
    <RangePicker value={range} onChange={setRange} compact={compact} />
  );
}
```
