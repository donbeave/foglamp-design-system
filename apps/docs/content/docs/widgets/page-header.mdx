## Public API

The table lists public exports used by this story. Prop names and TypeScript types come from the design-system source.

| Export | Prop | Type | Meaning |
| :--- | :--- | :--- | :--- |
| `PageHeader` | `title` | `string` | Sets the component heading or SVG title. |
|  | `titleLeading` | `ReactNode` | Content shown before the page title. |
|  | `titleTrailing` | `ReactNode` | Content shown after the page title. |
|  | `description` | `ReactNode` | Supporting page description. |
|  | `actions` | `ReactNode` | Renders the supplied action controls. |
|  | `back` | `PageHeaderBack \| undefined` | Back-navigation label and destination. |
|  | `icon` | `Icon \| undefined` | Icon component rendered beside the label. |
|  | `iconClassName` | `string \| undefined` | Adds a class to the leading icon. |
