## Public API

| Export | Prop | Type | Description |
| :--- | :--- | :--- | :--- |
| `BrandMark` | `className?` | `string` | CSS class applied to the Framerock three-frame architectural SVG mark. |

## Usage

```tsx
import { BrandMark } from "@tailrocks/framerock/icons/brand-mark";

export function BrandMarkExample() {
  return <BrandMark className="size-12" />;
}
```
