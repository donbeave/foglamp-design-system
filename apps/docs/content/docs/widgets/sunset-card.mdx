| `SunsetCard` | `serverUrl` | `string \| null \| undefined` | Server URL compared with the hosted-service URL before the notice renders. |

## Host URL behavior

`serverUrl` is optional. When omitted, the component reads `NEXT_PUBLIC_SERVER_URL` from the host environment. It renders only when the resolved value equals `https://api.foglamp.dev`; pass `null` to hide the notice for a self-hosted installation.

The source UI labels that hosted endpoint with a shutdown date of October 18, 2026. This page documents the component text and does not assert the current status of the hosted service.

```tsx
<SunsetCard serverUrl="https://api.foglamp.dev" />
<SunsetCard serverUrl={null} />
```
