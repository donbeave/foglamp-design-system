## Public API

The table lists public exports used by this story. Prop names and TypeScript types come from the design-system source.

| Export | Prop | Type | Meaning |
| :--- | :--- | :--- | :--- |
| `DevBarView` | `fps` | `number \| undefined` | Frames per second shown by the developer bar. |
|  | `queries` | `{ fetching: QueryDiagnostic[]; stale: QueryDiagnostic[]; staleInactive: number; } \| undefined` | Fetching, stale, and inactive query diagnostics. |
|  | `netDelay` | `number \| undefined` | Simulated network delay in milliseconds. |
|  | `netFail` | `boolean \| undefined` | Shows a simulated network failure. |
|  | `forceLoading` | `boolean \| undefined` | Forces loading indicators on. |
|  | `onNetworkDelayChange` | `((delay: DevNetworkDelay) => void) \| undefined` | Receives the selected network delay. |
|  | `onNetworkFailChange` | `((fail: boolean) => void) \| undefined` | Receives the network failure setting. |
|  | `onForceLoadingChange` | `((loading: boolean) => void) \| undefined` | Receives the forced-loading setting. |
|  | `onInvalidateQueries` | `(() => void) \| undefined` | Requests query invalidation from the host application. |
|  | `onClearQueries` | `(() => void) \| undefined` | Clears query diagnostics. |
|  | `onSendTestEmail` | `((variant: string) => void) \| undefined` | Receives the selected test email variant. |
|  | `sendingTestEmail` | `boolean \| undefined` | Marks a test email as sending. |

## Requirements

This view receives diagnostic snapshots and host actions as props. Supply `queries` and `fps`, then pass callbacks such as `onInvalidateQueries` for host actions. It does not fetch diagnostics itself.
