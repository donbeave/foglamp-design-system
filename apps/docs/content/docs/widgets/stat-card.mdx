## Public API

The table lists public exports used by this story. Prop names and TypeScript types come from the design-system source.

| Export | Prop | Type | Meaning |
| :--- | :--- | :--- | :--- |
| `StatCard` | `label` | `string` | Visible label text. |
|  | `href` | `string \| undefined` | Optional link destination. |
|  | `value` | `ReactNode` | Controlled value or source data passed to the component. |
|  | `hint` | `ReactNode` | Supporting hint shown near the value. |
|  | `prefix` | `ReactNode` | Text shown before the formatted value. |
|  | `suffix` | `ReactNode` | Text shown after the formatted value. |
|  | `formatValue` | `((n: number) => string) \| undefined` | Formats the value before display. |
|  | `delta` | `Delta \| null \| undefined` | Change value shown beside the main statistic. |
|  | `deltaInverted` | `boolean \| undefined` | Treats a negative delta as favorable. |
|  | `size` | `"sm" \| "default" \| undefined` | Selects the rendered icon size. |
|  | `icon` | `Icon \| undefined` | Icon component rendered beside the label. |
|  | `iconClassName` | `string \| undefined` | Adds a class to the leading icon. |
|  | `chart` | `ReactNode` | Sparkline data shown beside the statistic. |
|  | `loading` | `boolean \| undefined` | Controls the loading state. |
|  | `skeleton` | `boolean \| undefined` | Shows skeleton placeholders when true. |
|  | `chartPlaceholder` | `ReactNode` | Content shown when no chart data is available. |
