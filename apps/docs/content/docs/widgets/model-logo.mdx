## Public API


| Export | Prop | Type | Meaning |
| :--- | :--- | :--- | :--- |
| `ModelLogo` | `provider` | `string \| null \| undefined` | Model provider associated with the model. |
|  | `modelId` | `string \| null \| undefined` | Model identifier used to resolve its logo. |
|  | `className` | `string \| undefined` | Adds a class to the rendered root element. |

## Usage

```tsx
import { ModelLogo } from "@tailrocks/framerock/icons/model-logo";

export function ModelLogoExample({
  modelId = 'gpt-4o',
  provider = 'openai',
}: {
  modelId?: string;
  provider?: string;
} = {}) {
  return (
    <div className="flex items-center gap-3">
      <ModelLogo modelId={modelId} provider={provider} className="size-7" />
      <span className="text-sm">
        {modelId}
      </span>
    </div>
  );
}
```
