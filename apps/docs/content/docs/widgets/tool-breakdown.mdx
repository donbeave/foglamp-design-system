## Public API

| Export | Prop | Type | Description |
| :--- | :--- | :--- | :--- |
| `ToolBreakdownView` (`ToolBreakdownCard`) | `tools` | `readonly ToolBreakdownItem[]` | Per-tool call counts, error counts, and latency percentiles (`p50`, `p95`, `p99`). |
| | `isLoading?` | `boolean` | Renders skeleton rows while initial tool metrics load. |
| | `isUpdating?` | `boolean` | Dims the card while refreshed range data is loading. |
| | `title?` | `string` | Card heading text (defaults to `"Tool calls"`). |
| | `className?` | `string` | CSS class applied to the outer card. |



## Requirements

Pass the tool breakdown rows and resolved reporting range to the view. The story places the view in its shared range-provider frame.

## Usage

```tsx
import {
  ToolBreakdownView,
} from "@tailrocks/framerock/widgets/tool-breakdown";

const toolBreakdownFixture = [
  {
    toolName: "search_customers",
    callCount: 164,
    errorCount: 3,
    runCount: 98,
    totalRunCount: 120,
    latencyMs: { p50: 82, p95: 248, p99: 410 },
  },
  {
    toolName: "create_ticket",
    callCount: 72,
    errorCount: 1,
    runCount: 68,
    totalRunCount: 120,
    latencyMs: { p50: 121, p95: 360, p99: 540 },
  },
];

export function ToolBreakdownExample({
  isLoading = false,
}: {
  isLoading?: boolean;
} = {}) {
  return (
    <div className="w-full max-w-xl">
      <ToolBreakdownView tools={toolBreakdownFixture} isLoading={isLoading} />
    </div>
  );
}
```
