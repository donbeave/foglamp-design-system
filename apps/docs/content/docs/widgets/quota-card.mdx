## Public API


| Export | Prop | Type | Meaning |
| :--- | :--- | :--- | :--- |
| `QuotaCardView` | `usage` | `QuotaUsage \| null \| undefined` | Quota usage percentage data. |
|  | `billingHref` | `string \| undefined` | Destination for the billing action. |

## Usage

```tsx
import { QuotaCardView } from "@tailrocks/framerock/widgets/quota-card";

export function QuotaCardExample({
  pct = 0.94,
}: {
  pct?: number;
} = {}) {
  return (
    <div className="w-64">
      <QuotaCardView usage={{ spans: { pct } }} />
    </div>
  );
}
```
