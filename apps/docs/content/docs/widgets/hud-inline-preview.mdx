## Public API


| Export | Prop | Type | Meaning |
| :--- | :--- | :--- | :--- |
| `HudInlinePreview` | `stream` | `HudStream \| undefined` | Event source consumed by the HUD; omitted to leave it disconnected. |
|  | `defaultOpen` | `boolean \| undefined` | Starts the HUD expanded when true. |
|  | `theme` | `"light" \| "dark" \| "system" \| undefined` | HUD color mode; system follows the host theme. |
|  | `redact` | `boolean \| undefined` | Masks prompt, response, and tool payload text. |
| `createMockHudStream` | `initialEvents` | `readonly HudEvent[]` | Initial HUD events replayed by the local mock stream. |

## Requirements

The preview accepts a `HudStream`. Its story creates one with `createMockHudStream` from a local event list; it needs no server connection.

## Usage

```tsx
import { HudInlinePreview } from "@tailrocks/framerock/hud";
import { createMockHudStream } from "@tailrocks/framerock/hud";

const stream = createMockHudStream([{ type: 'trace.start', ts: Date.now(), traceId: 'trace-inline', name: 'Invoice extractor', agentName: 'Invoice extractor', provider: 'anthropic', model: 'claude-3-7-sonnet' }]);

export function HudInlinePreviewExample({
  redact = false,
}: {
  redact?: boolean;
} = {}) {
  return (
    <div className="relative h-[300px] w-full">
      <HudInlinePreview
        stream={stream}
        defaultOpen={false}
        redact={redact}
        theme="dark"
      />
    </div>
  );
}
```
