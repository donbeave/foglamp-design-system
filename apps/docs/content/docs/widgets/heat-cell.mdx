## Public API

The table lists public exports used by this story. Prop names and TypeScript types come from the design-system source.

| Export | Prop | Type | Meaning |
| :--- | :--- | :--- | :--- |
| `HeatCell` | `value` | `number \| null \| undefined` | Controlled value or source data passed to the component. |
|  | `thresholds` | `number[]` | Threshold values used to shade the cell. |
|  | `metric` | `"cost" \| "duration" \| "spend" \| undefined` | Metric displayed in the cell tooltip. |
|  | `bold` | `boolean \| undefined` | Uses bold text for the value. |
|  | `mutedWhenZero` | `boolean \| undefined` | Mutes the cell when its value is zero. |
|  | `children` | `ReactNode` | Content rendered inside the component. |
