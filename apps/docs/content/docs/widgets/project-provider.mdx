## Requirements

`useProject()` throws outside `ProjectProvider`. The provider accepts optional `projects`, `initialProjectId`, `isLoading`, and `onProjectChange` props. Its hook returns `project`, `projectId`, `projects`, `isLoading`, and `setProjectId`.

| Provider prop | Type | Meaning |
| :--- | :--- | :--- |
| `children` | `ReactNode` | Descendants that read project state. |
| `projects` | `Project[]` | Available projects. Defaults to one mock project. |
| `initialProjectId` | `string \| null` | Initial selection. Defaults to the first project ID. |
| `isLoading` | `boolean` | Loading state returned from `useProject()`. |
| `onProjectChange` | `(id: string) => void` | Receives a new project ID. The host owns route changes and persistence. |
