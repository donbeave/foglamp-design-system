## Public API

The table lists public exports used by this story. Prop names and TypeScript types come from the design-system source.

| Export | Prop | Type | Meaning |
| :--- | :--- | :--- | :--- |
| `ChartLegend` | `config` | `ChartConfig` | Labels and light/dark colors keyed by data series. |
|  | `selected` | `string \| null` | Current selected identifier, or null when nothing is selected. |
|  | `onSelect` | `(key: string \| null) => void` | Receives the selected item or series. |
| `themed` | `color` | `string` | Argument accepted by themed. |

## Requirements

`ChartLegend` is controlled by `selected` and `onSelect`. The module also exports bucket-formatting helpers and `useZoomRange`; that hook reads shared range state and requires `RangeProvider`.
