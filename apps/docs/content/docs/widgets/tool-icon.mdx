## Public API


| Export | Prop | Type | Meaning |
| :--- | :--- | :--- | :--- |
| `ToolIcon` | `name` | `string` | Name used to select the rendered label or icon. |
|  | `className` | `string \| undefined` | Adds a class to the rendered root element. |

## Usage

```tsx
import { ToolIcon } from "@tailrocks/framerock/widgets/leaf/tool-icon";

export function ToolIconExample({
  name = 'search_customers',
}: {
  name?: string;
} = {}) {
  return (
    <div className="flex items-center gap-2">
      <ToolIcon name={name} className="size-4" />
      <code className="text-xs">
        {name}
      </code>
    </div>
  );
}
```
