## Public API

The table lists public exports used by this story. Prop names and TypeScript types come from the design-system source.

| Export | Prop | Type | Meaning |
| :--- | :--- | :--- | :--- |
| `FoggyMessage` | `message` | `FoggyMessageData` | Foggy conversation message data. |

`FoggyMessageData` has an `id`, a `role` (`user`, `assistant`, or `system`), and a `parts` array. Text parts have `{ type: "text", text }`. Tool parts have a `tool-<name>` or `dynamic-tool` type, an optional `toolName`, and a state string.
