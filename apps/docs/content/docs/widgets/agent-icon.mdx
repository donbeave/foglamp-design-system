## Public API


| Export | Prop | Type | Meaning |
| :--- | :--- | :--- | :--- |
| `AgentIcon` | `name` | `string \| null \| undefined` | Name used to select the rendered label or icon. |
|  | `filled` | `boolean \| undefined` | Selects the filled or outline treatment. |
|  | `className` | `string \| undefined` | Adds a class to the rendered root element. |

## Usage

```tsx
import { AgentIcon } from "@tailrocks/framerock/widgets/leaf/agent-icon";

export function AgentIconExample({
  name = 'Support Assistant',
  filled = true,
}: {
  name?: string;
  filled?: boolean;
} = {}) {
  return (
    <div className="flex items-center gap-3">
      <AgentIcon name={name} filled={filled} className="size-8" />
      <span>
        {name}
      </span>
    </div>
  );
}
```
