## Public API

The table lists public exports used by this story. Prop names and TypeScript types come from the design-system source.

| Export | Prop | Type | Meaning |
| :--- | :--- | :--- | :--- |
| `PromptProseView` | `template` | `string` | Prompt template text to parse and render. |
|  | `slots` | `SlotExamples \| undefined` | Example values associated with named prompt slots. |
|  | `loading` | `boolean \| undefined` | Controls the loading state. |
|  | `className` | `string \| undefined` | Adds a class to the rendered root element. |

## Requirements

`PromptProseView` accepts the prompt template, slot examples, and loading state. `PromptProse` is the lower-level renderer for a template string and optional slot data.
