## Public API

| Export | Prop / Parameter | Type | Description |
| :--- | :--- | :--- | :--- |
| `PromptProseView` | `template` | `string` | Normalized prompt template text to parse and render. |
| | `slots` | `SlotExamples \| undefined` | Per-slot example values (`{ slots: { examples: { value: string; runs: number }[] }[] }`) displayed inside each `varies per run` hover card. |
| | `loading?` | `boolean` | Displays loading state inside slot hover cards while examples are being fetched. |
| | `className?` | `string` | CSS class applied to the root prose container. |
| `PromptProse` | `template`, `slots?`, `loading?`, `className?` | `{ template: string; versionId?: string; slotCount?: number; slots?: SlotExamples; loading?: boolean; className?: string }` | Wrapper around `PromptProseView` forwarding template and slot example props. |
| `parsePrompt` | `template` | `(template: string) => Block[]` | Parses a normalized prompt template into headings, paragraphs, lists, XML tags, horizontal rules, and `SLOT_LINE` slot blocks. |
| `estimateTokens` | `text` | `(text: string) => number` | Estimates token count from string length (`Math.ceil(text.length / 4)`). |



## Requirements

`PromptProseView` accepts the prompt template, slot examples, and loading state. `PromptProse` is the lower-level renderer for a template string and optional slot data.

## Usage

```tsx
import { PromptProseView } from "@tailrocks/framerock/widgets/prompt-prose";
import { SLOT_LINE } from "@tailrocks/framerock/lib/prompts/infer";
import { slotValues } from "@tailrocks/framerock/lib/prompts/slots";

const template = [
  '## Support assistant',
  '',
  'Answer clearly and use the workspace context before suggesting a fix.',
  SLOT_LINE,
  '## Response policy',
  '',
  'Never ask for or repeat secret credentials.',
  SLOT_LINE,
].join('\n');

const filledPrompt = [
  '## Support assistant',
  '',
  'Answer clearly and use the workspace context before suggesting a fix.',
  'Jordan is locked out after rotating an API key. Two production workers need the replacement key.',
  '## Response policy',
  '',
  'Never ask for or repeat secret credentials.',
  'Confirm both workers use the replacement key before revoking the old one.',
].join('\n');

const actualSlotValues = slotValues(template, filledPrompt);

const slots = {
  slots: actualSlotValues.map((value, index) => ({
    examples: value === null ? [] : [{ value, runs: index === 0 ? 18 : 12 }],
  })),
};

export function PromptProseExample({
  loading = false,
  label = 'Customer support prompt',
}: {
  loading?: boolean;
  label?: string;
} = {}) {
  return (
    <div className="w-full max-w-lg rounded-xl border bg-card p-4">
      {label ? (
          <div
            className="mb-3 border-b border-border/60 pb-2 text-xs font-medium text-muted-foreground"
          >
            {label}
          </div>
      ) : null}
      <PromptProseView template={template} slots={slots} loading={loading} />
    </div>
  );
}
```
