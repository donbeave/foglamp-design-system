## Public API


| Export | Prop | Type | Meaning |
| :--- | :--- | :--- | :--- |
| `UserMenuView` | `session` | `UserMenuSession \| null \| undefined` | User session displayed by the menu, or null when signed out. |
|  | `isPending` | `boolean \| undefined` | Marks the session action as pending. |
|  | `onSignOut` | `(() => void) \| undefined` | Runs when the user selects sign out. |
|  | `signInHref` | `string \| undefined` | Sign-in destination shown to signed-out users. |

## Usage

```tsx
import { UserMenuView } from "@tailrocks/framerock/widgets/user-menu";

export function UserMenuExample({
  signedIn = true,
}: {
  signedIn?: boolean;
} = {}) {
  return (
    <UserMenuView
      session={signedIn ? { user: { email: 'jordan@acme.dev' } } : null}
      onSignOut={() => undefined}
    />
  );
}
```
