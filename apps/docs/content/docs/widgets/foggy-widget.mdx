## Public API


| Export | Prop | Type | Meaning |
| :--- | :--- | :--- | :--- |
| `FoggyWidgetView` | `open` | `boolean` | Controls whether the assistant panel is open. |
|  | `onOpenChange` | `(open: boolean) => void` | Receives the next open state. |
|  | `messages` | `FoggyMessageData[] \| undefined` | Conversation messages shown in the panel. |
|  | `status` | `"ready" \| "submitted" \| "streaming" \| "error" \| undefined` | Selects the conversation submission state. |
|  | `error` | `Error \| undefined` | Error shown in the conversation panel. |
|  | `onSendMessage` | `((message: { text: string; }) => void \| Promise<void>) \| undefined` | Receives the submitted message text. |
|  | `onStop` | `(() => void \| Promise<void>) \| undefined` | Stops the active response. |
|  | `onRegenerate` | `(() => void \| Promise<void>) \| undefined` | Requests a new response for the current conversation. |
|  | `onNewChat` | `(() => void) \| undefined` | Starts a new conversation. |
|  | `threads` | `{ id: string; title: string; updatedAt: string; }[] \| undefined` | Thread records available in the history list. |
|  | `threadsLoading` | `boolean \| undefined` | Marks the thread list as loading. |
|  | `threadId` | `string \| undefined` | ID of the currently open thread. |
|  | `onLoadThreads` | `(() => void \| Promise<void>) \| undefined` | Requests the host to load the thread list. |
|  | `onOpenThread` | `((id: string) => void \| Promise<void>) \| undefined` | Receives the selected thread ID. |
|  | `onLayoutReserve` | `((target: number, element: HTMLElement \| null) => void) \| undefined` | Reports the panel layout reservation to the host. |

## Requirements

The Foggy view is driven by widget state and event callbacks from `@tailrocks/framerock/widgets/foggy/types`. It does not create a tRPC client or Next.js hook; pass host actions as props.

## Usage

```tsx
import { useState } from "react";
import { Button } from "@tailrocks/framerock/ui/button";
import {
  FoggyWidgetView,
} from "@tailrocks/framerock/widgets/foggy/foggy-widget";

const initialMessages = [
  { id: 'u1', role: 'user' as const, parts: [{ type: 'text' as const, text: 'Why did the latest trace fail?' }] },
  {
    id: 'a1',
    role: 'assistant' as const,
    parts: [{ type: 'text' as const, text: 'The customer lookup timed out. I found three recent failures in the staging project.' }],
  },
];

export function FoggyWidgetExample({
  status = 'ready',
}: {
  status?: 'ready' | 'submitted' | 'streaming' | 'error';
} = {}) {
  const [open, setOpen] = useState(true);
  const [messages, setMessages] = useState(initialMessages);
  return (
    <div className="relative flex h-[540px] w-full flex-col justify-between">
      <div
        className="flex items-center justify-between gap-2 rounded-lg border bg-card px-3 py-2 text-xs text-muted-foreground"
      >
        <span>
          Assistant status:
          <strong className="text-foreground">
            {status}
          </strong>
          (
          {messages.length}
          messages)
        </span>
        {!open ? (
            <Button size="xs" variant="outline" onClick={() => setOpen(true)}>
              Reopen Foggy
            </Button>
        ) : null}
      </div>
      <div className="relative flex-1">
        <FoggyWidgetView
          open={open}
          onOpenChange={setOpen}
          messages={messages}
          status={status}
          onSendMessage={({ text }) => { const trimmed = text.trim(); if (!trimmed) return; setMessages((prev) => [ ...prev, { id: `u-${prev.length + 1}`, role: 'user' as const, parts: [{ type: 'text' as const, text: trimmed }] }, { id: `a-${prev.length + 2}`, role: 'assistant' as const, parts: [{ type: 'text' as const, text: `Checked recent spans for "${trimmed}". No additional errors found in the active window.` }], }, ]); window.dispatchEvent(new CustomEvent('framerock-story:message', { detail: trimmed })); }}
        />
      </div>
    </div>
  );
}
```
