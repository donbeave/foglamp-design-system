## Public API

The table lists public exports used by this story. Prop names and TypeScript types come from the design-system source.

| Export | Prop | Type | Meaning |
| :--- | :--- | :--- | :--- |
| `FoggyWidgetView` | `open` | `boolean` | Controls whether the assistant panel is open. |
|  | `onOpenChange` | `(open: boolean) => void` | Receives the next open state. |
|  | `messages` | `FoggyMessageData[] \| undefined` | Conversation messages shown in the panel. |
|  | `status` | `"ready" \| "submitted" \| "streaming" \| "error" \| undefined` | Selects the conversation submission state. |
|  | `error` | `Error \| undefined` | Error shown in the conversation panel. |
|  | `onSendMessage` | `((message: { text: string; }) => void \| Promise<void>) \| undefined` | Receives the submitted message text. |
|  | `onStop` | `(() => void \| Promise<void>) \| undefined` | Stops the active response. |
|  | `onRegenerate` | `(() => void \| Promise<void>) \| undefined` | Requests a new response for the current conversation. |
|  | `onNewChat` | `(() => void) \| undefined` | Starts a new conversation. |
|  | `threads` | `{ id: string; title: string; updatedAt: string; }[] \| undefined` | Thread records available in the history list. |
|  | `threadsLoading` | `boolean \| undefined` | Marks the thread list as loading. |
|  | `threadId` | `string \| undefined` | ID of the currently open thread. |
|  | `onLoadThreads` | `(() => void \| Promise<void>) \| undefined` | Requests the host to load the thread list. |
|  | `onOpenThread` | `((id: string) => void \| Promise<void>) \| undefined` | Receives the selected thread ID. |
|  | `onLayoutReserve` | `((target: number, element: HTMLElement \| null) => void) \| undefined` | Reports the panel layout reservation to the host. |

## Requirements

The Foggy view is driven by widget state and event callbacks from `@tailrocks/framerock/widgets/foggy/types`. It does not create a tRPC client or Next.js hook; pass host actions as props.
