## Public API

The table lists public exports used by this story. Prop names and TypeScript types come from the design-system source.

| Export | Prop | Type | Meaning |
| :--- | :--- | :--- | :--- |
| `AnthropicLogo` | `className` | `string \| undefined` | Adds a class to the rendered root element. |
| `GoogleLogo` | `className` | `string \| undefined` | Adds a class to the rendered root element. |
| `OpenAILogo` | `className` | `string \| undefined` | Adds a class to the rendered root element. |
| `MistralLogo` | `className` | `string \| undefined` | Adds a class to the rendered root element. |
