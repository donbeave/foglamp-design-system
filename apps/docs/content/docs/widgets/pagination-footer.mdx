## Public API

The table lists public exports used by this story. Prop names and TypeScript types come from the design-system source.

| Export | Prop | Type | Meaning |
| :--- | :--- | :--- | :--- |
| `PaginationFooter` | `page` | `number` | Zero-based current page index. |
|  | `pageSize` | `number` | Maximum number of rows on one page. |
|  | `total` | `number` | Total number of matching rows. |
|  | `shown` | `number` | Number of rows currently rendered. |
|  | `noun` | `[string, string]` | Singular and plural labels for the paginated item. |
|  | `onPageChange` | `(page: number) => void` | Receives the requested page index. |
|  | `onPageSizeChange` | `((size: number) => void) \| undefined` | Receives the newly selected page size. |
|  | `pageSizes` | `number[] \| undefined` | Lists the page sizes offered in the selector. |
|  | `isFetching` | `boolean \| undefined` | Marks the page data as fetching. |
