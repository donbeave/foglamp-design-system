## Public API

The table lists public exports used by this story. Prop names and TypeScript types come from the design-system source.

| Export | Prop | Type | Meaning |
| :--- | :--- | :--- | :--- |
| `SearchInput` | `value` | `string` | Controlled value or source data passed to the component. |
|  | `onChange` | `(value: string) => void` | Receives the next value when the user changes the control. |
|  | `placeholder` | `string \| undefined` | Text shown while the field is empty. |
|  | `className` | `string \| undefined` | Adds a class to the rendered root element. |
