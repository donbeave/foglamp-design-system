## Public API


| Export | Prop | Type | Meaning |
| :--- | :--- | :--- | :--- |
| `Stat` | `label` | `string` | Visible label text. |
|  | `value` | `ReactNode` | Controlled value or source data passed to the component. |
|  | `emphasis` | `boolean \| undefined` | Uses the emphasized value treatment. |
|  | `className` | `string \| undefined` | Adds a class to the rendered root element. |
|  | `valueClassName` | `string \| undefined` | Adds a class to the value text. |

## Usage

```tsx
import { Stat } from "@tailrocks/framerock/widgets/leaf/stat";

export function StatExample({
  label = 'Runs',
  value = '1,284',
  emphasis = true,
}: {
  label?: string;
  value?: string;
  emphasis?: boolean;
} = {}) {
  return <Stat label={label} value={value} emphasis={emphasis} />;
}
```
