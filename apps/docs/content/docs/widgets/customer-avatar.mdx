## Public API


| Export | Prop | Type | Meaning |
| :--- | :--- | :--- | :--- |
| `CustomerAvatar` | `customerId` | `string` | Customer ID used to derive the avatar. |
|  | `customerName` | `string \| null \| undefined` | Customer name used for the avatar label. |
|  | `imageUrl` | `string \| null \| undefined` | Image URL used by the avatar. |
|  | `filled` | `boolean \| undefined` | Selects the filled or outline treatment. |
|  | `className` | `string \| undefined` | Adds a class to the rendered root element. |

## Usage

```tsx
import {
  CustomerAvatar,
} from "@tailrocks/framerock/widgets/leaf/customer-avatar";

export function CustomerAvatarExample({
  customerId = 'cus_8d2f',
  customerName = 'Jordan Lee',
  filled = true,
}: {
  customerId?: string;
  customerName?: string;
  filled?: boolean;
} = {}) {
  return (
    <div className="flex items-center gap-3">
      <CustomerAvatar
        customerId={customerId}
        customerName={customerName}
        filled={filled}
      />
      <span className="text-sm">
        {customerName}
        ·
        {customerId}
      </span>
    </div>
  );
}
```
