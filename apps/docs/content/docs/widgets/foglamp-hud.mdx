## Public API


| Export | Prop | Type | Meaning |
| :--- | :--- | :--- | :--- |
| `FoglampHUD` | `stream` | `HudStream \| undefined` | Event source consumed by the HUD; omitted to leave it disconnected. |
|  | `defaultOpen` | `boolean \| undefined` | Starts the HUD expanded when true. |
|  | `theme` | `"light" \| "dark" \| "system" \| undefined` | HUD color mode; system follows the host theme. |
|  | `redact` | `boolean \| undefined` | Masks prompt, response, and tool payload text. |
| `createMockHudStream` | `initialEvents` | `readonly HudEvent[]` | Initial HUD events replayed by the local mock stream. |

## Requirements

`FoglampHUD` does not open a network connection. Pass an explicit `HudStream` when you want events. `createMockHudStream(events)` creates a local stream from `HudEvent[]`. The HUD props are `stream`, `defaultOpen`, `theme`, and `redact`.

## Usage

```tsx
import { FoglampHUD, createMockHudStream } from "@tailrocks/framerock/hud";

const now = Date.now();

const stream = createMockHudStream([
  {
    type: 'trace.start',
    ts: now,
    traceId: 'trace-demo-1',
    name: 'Support assistant',
    agentName: 'Support assistant',
    provider: 'openai',
    model: 'gpt-4o',
  },
  {
    type: 'step.start',
    ts: now + 10,
    traceId: 'trace-demo-1',
    stepNumber: 0,
    provider: 'openai',
    model: 'gpt-4o',
  },
  {
    type: 'tool.start',
    ts: now + 40,
    traceId: 'trace-demo-1',
    toolCallId: 'call_lookup_1',
    toolName: 'lookupCustomerAccount',
    input: JSON.stringify({ email: 'jordan@acme.example', workspace: 'production' }),
  },
  {
    type: 'tool.end',
    ts: now + 110,
    traceId: 'trace-demo-1',
    toolCallId: 'call_lookup_1',
    toolName: 'lookupCustomerAccount',
    status: 'ok',
    durationMs: 70,
    output: JSON.stringify({ accountId: 'acct_01HZXA29', activeWorkers: 2, pendingRotation: true }),
  },
  {
    type: 'step.end',
    ts: now + 120,
    traceId: 'trace-demo-1',
    stepNumber: 0,
    status: 'ok',
    durationMs: 110,
    outputTps: 118,
  },
  {
    type: 'step.start',
    ts: now + 130,
    traceId: 'trace-demo-1',
    stepNumber: 1,
    provider: 'openai',
    model: 'gpt-4o',
  },
  {
    type: 'step.tokens',
    ts: now + 260,
    traceId: 'trace-demo-1',
    stepNumber: 1,
    outputTokens: 64,
    tps: 124,
  },
]);

export function FoglampHUDExample({
  defaultOpen = true,
  redact = false,
  hudTheme = 'dark',
}: {
  defaultOpen?: boolean;
  redact?: boolean;
  hudTheme?: 'light' | 'dark';
} = {}) {
  return (
    <div className="relative h-[540px] w-full">
      <FoglampHUD
        key={`${defaultOpen}-${hudTheme}-${redact}`}
        stream={stream}
        defaultOpen={defaultOpen}
        redact={redact}
        theme={hudTheme}
      />
    </div>
  );
}
```
