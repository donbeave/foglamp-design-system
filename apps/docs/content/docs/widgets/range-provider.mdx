## Public API

| Export | Prop / Return | Type | Description |
| :--- | :--- | :--- | :--- |
| `RangeProvider` | `children` | `ReactNode` | Descendant components that read or update the shared reporting time range. |
| `useRange` | `returns` | `RangeContextValue` | Returns `{ range, setRange }` and persists preset selections in `localStorage`. Throws if called outside `RangeProvider`. |



## Requirements

`useRange()` throws outside `RangeProvider`. The provider accepts `children` and stores the selected range under the `foglamp.range` key.

`RangeProvider` accepts `children: ReactNode`. `useRange()` returns the current `RangeValue` and `setRange(range)`. The provider restores and stores the selected range in browser `localStorage`.

## Usage

```tsx
import { resolvePreset } from "@tailrocks/framerock/lib/range";
import {
  RangeProvider,
  useRange,
} from "@tailrocks/framerock/widgets/range-context";

function RangeControls() {
  const { range, setRange } = useRange();
  return (
    <div className="flex items-center gap-3">
      <span className="text-sm">{range.label}</span>
      <button
        type="button"
        className="rounded-md border px-2 py-1 text-xs"
        onClick={() => setRange(resolvePreset("24h"))}
      >
        Set 24h range
      </button>
    </div>
  );
}

export function RangeProviderExample() {
  return (
    <RangeProvider>
      <RangeControls />
    </RangeProvider>
  );
}
```
