## Public API


| Export | Prop | Type | Meaning |
| :--- | :--- | :--- | :--- |
| `AnimatedApiKey` | `from` | `string` | Label replaced by the animated key value. |
|  | `value` | `string` | Controlled value or source data passed to the component. |
|  | `className` | `string \| undefined` | Adds a class to the rendered root element. |

## Usage

```tsx
import {
  AnimatedApiKey,
} from "@tailrocks/framerock/widgets/animated-api-key";

export function AnimatedApiKeyExample({
  from = 'production key',
  value = 'sk_live_framerock_7Kp4qR2v',
}: {
  from?: string;
  value?: string;
} = {}) {
  return (
    <div className="rounded-md border bg-card px-3 py-2">
      <AnimatedApiKey from={from} value={value} />
    </div>
  );
}
```
