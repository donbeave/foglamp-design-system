## Public API


| Export | Prop | Type | Meaning |
| :--- | :--- | :--- | :--- |
| `CopyIcon` | `copied` | `boolean` | Shows the copied confirmation state. |
|  | `className` | `string \| undefined` | Adds a class to the rendered root element. |
|  | `checkClassName` | `string \| undefined` | Adds a class to the copied-state check mark. |

## Usage

```tsx
import { CopyIcon } from "@tailrocks/framerock/widgets/leaf/copy-icon";

export function CopyIconExample({
  copied = false,
}: {
  copied?: boolean;
} = {}) {
  return (
    <div className="flex items-center gap-4">
      <span className="flex items-center gap-2">
        <CopyIcon copied={false} className="size-4" />
        Copy
      </span>
      <span className="flex items-center gap-2">
        <CopyIcon copied={copied} className="size-4" />
        {copied ? 'Copied' : 'Ready'}
      </span>
    </div>
  );
}
```
