## Public API

The table lists public exports used by this story. Prop names and TypeScript types come from the design-system source.

| Export | Prop | Type | Meaning |
| :--- | :--- | :--- | :--- |
| `FilterSelect` | `value` | `"" \| T` | Controlled value or source data passed to the component. |
|  | `onChange` | `(value: T \| "") => void` | Receives the next value when the user changes the control. |
|  | `allLabel` | `string` | Label for the unfiltered option. |
|  | `options` | `{ value: T; label: string; hint?: string; icon?: ComponentType<{ className?: string; }>; }[]` | Selectable values and their display labels. |
|  | `icon` | `ComponentType<{ className?: string; }> \| undefined` | Icon component rendered beside the label. |
|  | `className` | `string \| undefined` | Adds a class to the rendered root element. |
|  | `allowFreeText` | `boolean \| undefined` | Allows values outside the listed options. |
