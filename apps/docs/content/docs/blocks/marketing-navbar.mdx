## Public API

| Export | Prop | Type | Description |
| :--- | :--- | :--- | :--- |
| `MarketingNavbar` | `links?` | `MarketingNavLink[]` | Top-level navigation links rendered in the navbar. |
|  | `loggedIn?` | `boolean` | Switches the primary navbar CTA between Sign in and Dashboard. |
|  | `homeHref?` | `string` | Destination href for the back-to-home navigation link. |
|  | `loginHref?` | `string` | Destination href for the sign-in button. |
|  | `dashboardHref?` | `string` | Destination href for the dashboard button. |
|  | `githubHref?` | `string` | External repository URL for the GitHub icon link. |
|  | `brandName?` | `string` | Brand wordmark text (defaults to `"Framerock"`). |
|  | `onLoginShortcut?` | `() => void` | Callback fired when the keyboard login shortcut is pressed. |

## Usage

```tsx
import {
  MarketingNavbar,
} from "@tailrocks/framerock/blocks/marketing/chrome/navbar";

export function MarketingNavbarExample({
  compact = false,
}: {
  compact?: boolean;
} = {}) {
  return (
    <div className={`w-full ${compact ? 'min-h-[120px]' : 'min-h-[240px]'}`}>
      <MarketingNavbar brandName="Framerock" />
    </div>
  );
}
```
