Marketing Navbar renders the source marketing navigation with its standard link layout. The story’s `compact` control changes only the preview stage height; it is not passed to the navbar.

<story.WithControl />

## Package entry

`@foglamp/design-system/blocks/marketing/chrome/navbar` exports this block. The interactive preview above comes from `apps/docs/src/stories/blocks/marketing-navbar.story.tsx`.

## API reference

| Entry | Contract |
| --- | --- |
| Story arguments | `compact: boolean`; initial values are `compact: false` |
| Fixture and callback wiring | The story exposes `compact` as a frame-height control. `MarketingNavbar` receives no props in this story. |
| Registry item | `block-marketing-chrome-navbar`. The portal payload is `/r/block-marketing-chrome-navbar.json`. |
