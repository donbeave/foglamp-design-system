<story.WithControl />

## Package entry

`@foglamp/design-system/blocks/dashboard/traces-explorer-block` exports this block. The interactive preview above comes from `apps/docs/src/stories/blocks/traces-explorer-block.story.tsx`.

## API reference

| Entry | Contract |
| --- | --- |
| Story arguments | `isLoading: boolean`, `isFetching: boolean`; initial values are `isLoading: false, isFetching: false` |
| Fixture and callback wiring | The story exposes `isLoading` and `isFetching`. It wires `onTraceSelect` to the inspector view and supplies a no-op `onFiltersChange`; trace and prompt-version data use source defaults. |
| Registry item | `block-dashboard-traces-explorer`. The portal payload is `/r/block-dashboard-traces-explorer.json`. |
