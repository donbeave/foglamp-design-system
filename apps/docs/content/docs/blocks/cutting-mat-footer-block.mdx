## Public API

| Export | Prop | Type | Description |
| :--- | :--- | :--- | :--- |
| `CuttingMatFooterBlock` | `brandName?` | `string` | Brand wordmark text (defaults to `"Framerock"`). |
|  | `columns?` | `FooterColumn[]` | Navigation link columns rendered in the footer grid. |
|  | `copyrightText?` | `string` | Copyright notice displayed in the footer bottom bar. |

## Usage

```tsx
import {
  CuttingMatFooterBlock,
} from "@tailrocks/framerock/blocks/marketing/chrome/footer";

export function CuttingMatFooterBlockExample() {
  return <CuttingMatFooterBlock />;
}
```
