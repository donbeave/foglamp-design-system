## Public API

| Export | Prop | Type | Description |
| :--- | :--- | :--- | :--- |
| `DriftingFogCtaBlock` | `prompt?` | `string` | Onboarding or instrumentation prompt copied by the CTA button. |
|  | `startFreeHref?` | `string` | Destination href for the primary action button. |
|  | `onPromptCopied?` | `() => void` | Callback fired after the prompt is copied to the clipboard. |
