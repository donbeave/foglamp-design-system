## Public API

| Export | Prop | Type | Description |
| :--- | :--- | :--- | :--- |
| `AppShellBlock` | `children` | `ReactNode` | Nested route or layout content rendered inside the shell. |
|  | `pathname?` | `string` | Active route pathname used to highlight navigation items. |
|  | `projects?` | `Project[]` | Available workspace projects displayed in the project switcher. |
|  | `initialProjectId?` | `string \| null` | Initially selected project identifier. |
|  | `isLoading?` | `boolean` | Renders loading skeleton placeholders while data is being fetched. |
|  | `onProjectChange?` | `(id: string) => void` | Callback fired when the active project selection changes. |
|  | `onNewProject?` | `(input: NewProjectInput) => Project \| Promise<Project>` | Callback fired to create a new project from the dialog. |
|  | `projectDialogOpen?` | `boolean` | Controlled open state for the new-project dialog. |
|  | `onProjectDialogOpenChange?` | `(open: boolean) => void` | Callback fired when the new-project dialog open state changes. |
|  | `serverUrl?` | `string` | Self-hosted server endpoint displayed in the developer bar. |
|  | `quotaUsage?` | `QuotaUsage \| null` | Monthly span usage and limit shown in the sidebar quota card. |
|  | `devBar?` | `DevBarViewProps` | Configuration for the local developer environment status bar. |
|  | `hud?` | `FoglampHUDProps` | Props forwarded to the embedded live HUD overlay. |
|  | `isPlatformAdmin?` | `boolean` | Enables platform administrator navigation controls. |
|  | `foggy?` | `Omit<FoggyWidgetViewProps, "open" \| "onOpenChange">` | Props forwarded to the embedded Foggy assistant drawer. |
|  | `footer?` | `ReactNode` | Custom footer content rendered at the bottom of the sidebar. |
|  | `user?` | `{ name: string; email?: string; image?: string }` | Signed-in user profile displayed in the account menu. |
|  | `onSignOut?` | `() => void` | Callback invoked when the user selects sign out. |

## Usage

```tsx
import {
  AppShellBlock,
} from "@tailrocks/framerock/blocks/app-shell/app-shell-block";
import type { Project } from "@tailrocks/framerock/widgets/project-context";

const projects: Project[] = [
  {
    id: "prod",
    name: "Acme Production",
    slug: "acme-production",
    url: null,
    orgId: "org-acme",
    orgName: "Acme",
    orgSlug: "acme",
  },
];

export function AppShellExample() {
  return (
    <AppShellBlock
      pathname="/overview"
      projects={projects}
      user={{ name: "Alex Rivera", email: "alex@example.com" }}
    >
      <section className="px-6 py-4">
        <h2 className="text-xl font-semibold">Overview</h2>
        <p className="mt-1 text-sm text-muted-foreground">
          Workspace metrics and active traces render inside the shell outlet.
        </p>
      </section>
    </AppShellBlock>
  );
}
```
