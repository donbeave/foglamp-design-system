Instrument Empty State presents the first-instrument prompt for an agent, workflow, or session. The story uses BrandMark as its icon and supplies a fixed description.

## Package entry

`@foglamp/design-system/blocks/auth/instrument-empty-state` exports this block. The interactive preview above comes from `apps/docs/src/stories/blocks/instrument-empty-state-block.story.tsx`.

## API reference

| Entry | Contract |
| --- | --- |
| Story arguments | `feature: 'agent' | 'workflow' | 'session'`, `title: string`; initial values are `feature: 'agent', title: 'No agent traces yet'` |
| Fixture and callback wiring | The story exposes `feature` (`agent`, `workflow`, or `session`) and `title`. It supplies `icon` and `description` as fixed content. |
| Registry item | `block-auth-instrument-empty-state`. The portal payload is `/r/block-auth-instrument-empty-state.json`. |
