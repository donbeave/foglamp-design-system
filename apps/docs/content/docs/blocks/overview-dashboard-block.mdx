Overview Dashboard renders the source observability dashboard with its default local data. The story controls the updating state and provides the dashboard shell.

## Package entry

`@foglamp/design-system/blocks/dashboard/overview-dashboard-block` exports this block. The interactive preview above comes from `apps/docs/src/stories/blocks/overview-dashboard-block.story.tsx`.

## API reference

| Entry | Contract |
| --- | --- |
| Story arguments | `isUpdating: boolean`; initial values are `isUpdating: false` |
| Fixture and callback wiring | The story exposes `isUpdating`. The source block also accepts optional dashboard data, loading state, and onboarding content. |
| Registry item | `block-dashboard-overview-dashboard`. The portal payload is `/r/block-dashboard-overview-dashboard.json`. |
