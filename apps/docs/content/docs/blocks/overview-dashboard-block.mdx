## Public API

| Export | Prop | Type | Description |
| :--- | :--- | :--- | :--- |
| `OverviewDashboardBlock` | `data?` | `OverviewDashboardData` | Structured dataset rendered by the block. |
|  | `isLoading?` | `boolean` | Renders loading skeleton placeholders while data is being fetched. |
|  | `isUpdating?` | `boolean` | Holds the current view while refreshed data is loading. |
|  | `onboarding?` | `{ apiKey?: string \| null; prompt?: string; docsUrl?: string; onPromptCopied?: () => void }` | Onboarding configuration shown before the first trace arrives. |

## Usage

```tsx
import {
  OverviewDashboardBlock,
} from "@tailrocks/framerock/blocks/dashboard/overview-dashboard-block";

export function OverviewExample({
  isUpdating = false,
}: {
  isUpdating?: boolean;
} = {}) {
  return <OverviewDashboardBlock isUpdating={isUpdating} />;
}
```
