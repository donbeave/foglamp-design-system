Login Form presents the authentication methods enabled by its configuration. The story toggles the magic-link method and replaces the form with a local signed-in status after completion.

<story.WithControl />

## Package entry

`@foglamp/design-system/blocks/auth/login-form` exports this block. The interactive preview above comes from `apps/docs/src/stories/blocks/login-form-block.story.tsx`.

## API reference

| Entry | Contract |
| --- | --- |
| Story arguments | `magicLink: boolean`; initial values are `magicLink: true` |
| Fixture and callback wiring | The story exposes `magicLink`. It enables email/password and Google methods, and tracks the `onSignedIn` completion locally. The exported block accepts a methods configuration and an `onSignedIn` callback. |
| Registry item | `block-auth-login-form`. The portal payload is `/r/block-auth-login-form.json`. |
