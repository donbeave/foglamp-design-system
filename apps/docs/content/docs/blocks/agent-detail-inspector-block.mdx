Agent Detail Inspector displays an agent summary with a selectable trace detail. The story keeps the selected trace in local React state and renders the block inside DashboardStoryShell.

<story.WithControl />

## Package entry

`@foglamp/design-system/blocks/dashboard/agent-detail-inspector-block` exports this block. The interactive preview above comes from `apps/docs/src/stories/blocks/agent-detail-inspector-block.story.tsx`.

## API reference

| Entry | Contract |
| --- | --- |
| Story arguments | `agentName: string`, `isUpdating: boolean`; initial values are `agentName: 'Support agent', isUpdating: false` |
| Fixture and callback wiring | The story exposes `agentName` and `isUpdating`. `onTraceChange` updates the selected trace locally, and `onNavigate` is a no-op. |
| Registry item | `block-dashboard-agent-detail-inspector`. The portal payload is `/r/block-dashboard-agent-detail-inspector.json`. |
