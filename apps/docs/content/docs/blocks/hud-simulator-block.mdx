## Package entry

`@foglamp/design-system/blocks/marketing/hud-landing` exports this block. The interactive preview above comes from `apps/docs/src/stories/blocks/hud-simulator-block.story.tsx`.

## API reference

| Entry | Contract |
| --- | --- |
| Story arguments | No editable workbench arguments. |
| Fixture and callback wiring | The source block accepts optional `homeHref`, defaulting to `/homepage`. The story exposes `homeHref` so the destination can be changed in the workbench. |
| Registry item | `block-marketing-hud-landing`. The portal payload is `/r/block-marketing-hud-landing.json`. |
