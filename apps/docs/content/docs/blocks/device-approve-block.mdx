## Public API

| Export | Prop | Type | Description |
| :--- | :--- | :--- | :--- |
| `DeviceApproveBlock` | `initialUserCode` | `string` | Pre-filled 8-character device verification code. |
|  | `userEmail?` | `string \| null` | Signed-in user email address displayed on the approval screen. |
|  | `onClaim?` | `(input: { userCode: string; userEmail?: string \| null; }) => Promise<DeviceClaimResult>` | Async handler that validates and claims the entered device code. |
|  | `onDecision?` | `(input: { userCode: string; action: "approve" \| "deny"; }) => Promise<DeviceDecisionResult>` | Async handler invoked when the user approves or denies the device. |
|  | `onApproved?` | `(input: { userCode: string }) => void` | Callback fired after device authorization succeeds. |

## Usage

```tsx
import {
  DeviceApproveBlock,
} from "@tailrocks/framerock/blocks/auth/device-approve";

export function DeviceApproveExample({
  initialUserCode = 'ABCD-1234',
}: {
  initialUserCode?: string;
} = {}) {
  return (
    <div className="flex w-full justify-center">
      <DeviceApproveBlock
        key={initialUserCode}
        initialUserCode={initialUserCode}
        userEmail="alex@example.com"
        onClaim={async () => ({ kind: 'pending' })}
        onDecision={async () => ({ kind: 'success' })}
      />
    </div>
  );
}
```
