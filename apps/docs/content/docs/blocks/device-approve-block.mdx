Device Approval presents a device authorization code and the approval decision flow. The story supplies a demo email and local asynchronous claim and decision handlers.

<story.WithControl />

## Package entry

`@foglamp/design-system/blocks/auth/device-approve` exports this block. The interactive preview above comes from `apps/docs/src/stories/blocks/device-approve-block.story.tsx`.

## API reference

| Entry | Contract |
| --- | --- |
| Story arguments | `initialUserCode: string`; initial values are `initialUserCode: 'ABCD-1234'` |
| Fixture and callback wiring | The story exposes `initialUserCode`. It supplies `userEmail`, `onClaim`, and `onDecision`; the mock claim returns a pending result and the mock decision returns success. |
| Registry item | `block-auth-device-approve`. The portal payload is `/r/block-auth-device-approve.json`. |
