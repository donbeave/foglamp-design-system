## Public API

| Export | Prop | Type | Description |
| :--- | :--- | :--- | :--- |
| `TraceWaterfallInspectorBlock` | `traceId?` | `string` | Active trace identifier. |
|  | `data?` | `TraceInspectorData \| null` | Structured dataset rendered by the block. |
|  | `isLoading?` | `boolean` | Renders loading skeleton placeholders while data is being fetched. |
|  | `scores?` | `TraceScore[]` | Individual evaluation score rows. |
|  | `evals?` | `(EvalMeta & { id: string })[]` | Configures `evals`. |
|  | `presets?` | `{ id: string; name: string }[]` | Available evaluation rubric presets. |
|  | `neighbors?` | `{ prev: { traceId: string } \| null; next: { traceId: string } \| null } \| null` | Adjacent trace links (`prev` and `next`) for keyboard navigation. |
|  | `comparison?` | `{ durationPercentile: number \| null; costPercentile: number \| null; tokenPercentile: number \| null } \| null` | Percentile rankings comparing trace duration, cost, and tokens. |
|  | `initialSpanId?` | `string` | Initially selected span identifier in the waterfall. |
|  | `onSpanChange?` | `(spanId: string \| null) => void` | Callback fired when the selected span changes. |

## Usage

```tsx
import { useState } from "react";
import {
  TraceWaterfallInspectorBlock,
} from "@tailrocks/framerock/blocks/dashboard/trace-waterfall-inspector-block";

export function TraceWaterfallExample({
  isLoading = false,
}: {
  isLoading?: boolean;
} = {}) {
  const [span, setSpan] = useState<string | null>(null);
  return (
    <TraceWaterfallInspectorBlock
      isLoading={isLoading}
      initialSpanId={span ?? undefined}
      onSpanChange={setSpan}
    />
  );
}
```
