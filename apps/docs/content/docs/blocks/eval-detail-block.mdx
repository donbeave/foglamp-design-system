## Public API

| Export | Prop | Type | Description |
| :--- | :--- | :--- | :--- |
| `EvalDetailBlock` | `evalId?` | `string` | Active evaluation identifier. |
|  | `definition?` | `EvalDefinition \| null` | Evaluation scorer configuration, thresholds, and model settings. |
|  | `presets?` | `{ id: string; name: string; prompt: string }[]` | Available evaluation rubric presets. |
|  | `providers?` | `{ provider: string }[]` | Configured model providers available for LLM judges. |
|  | `series?` | `EvalSeries[]` | Time-bucketed evaluation pass rate and score series. |
|  | `scores?` | `EvalScore[]` | Individual evaluation score rows. |
|  | `total?` | `number` | Total number of matching rows across all pages. |
|  | `isLoading?` | `boolean` | Renders loading skeleton placeholders while data is being fetched. |
|  | `focusedScoreId?` | `string \| null` | Currently inspected score identifier. |
|  | `focusedScore?` | `EvalScore \| null` | Full score record for the open inspection drawer. |
|  | `onQueryChange?` | `(query: { page: number; pageSize: number; sort: { key: "score"; dir: "asc" \| "desc" } \| null; from: Date; to: Date }) => void` | Callback fired when pagination, sorting, or date range changes. |
|  | `onUpdate?` | `(value: EvalUpdate) => void \| Promise<void>` | Callback fired when the evaluation configuration is saved. |
|  | `traces?` | `Record<string, TraceSpan[]>` | Map of trace IDs to span arrays for the trace waterfall preview. |
|  | `judgeInputs?` | `Record<string, EvalJudgeInput>` | Map of score IDs to rendered judge prompt inputs and segments. |

## Usage

```tsx
import {
  EvalDetailBlock,
} from "@tailrocks/framerock/blocks/dashboard/eval-detail-block";

export function EvalDetailExample({
  evalId = 'eval-support-quality',
  isLoading = false,
}: {
  evalId?: string;
  isLoading?: boolean;
} = {}) {
  return (
    <EvalDetailBlock
      evalId={evalId}
      isLoading={isLoading}
      onUpdate={async () => {}}
      onQueryChange={() => {}}
    />
  );
}
```
