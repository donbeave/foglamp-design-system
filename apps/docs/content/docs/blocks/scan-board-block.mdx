Scan Board renders the full scan result from the story fixture. The story provides favicon resolution through ScanFaviconProvider.

<story.WithControl />

## Package entry

`@foglamp/design-system/blocks/scan/scan-board` exports this block. The interactive preview above comes from `apps/docs/src/stories/blocks/scan-board-block.story.tsx`.

## API reference

| Entry | Contract |
| --- | --- |
| Story arguments | No editable workbench arguments. |
| Fixture and callback wiring | The source board receives a `ScanData` value. The story uses `scanFixture`; mount the board under `ScanFaviconProvider` when favicon resolution is required. |
| Registry item | `block-scan-scan-board`. The portal payload is `/r/block-scan-scan-board.json`. |
