## Package entry

`@tailrocks/framerock/blocks/scan/scan-board` exports this block. The interactive preview above comes from `apps/docs/src/stories/blocks/scan-board-block.story.tsx`.

## API reference

| Entry | Contract |
| --- | --- |
| Story arguments | No editable workbench arguments. |
| Fixture and callback wiring | The source board receives a `ScanData` value. The story uses `scanFixture`; mount the board under `ScanFaviconProvider` when favicon resolution is required. |
| Registry item | `block-scan-scan-board`. The portal payload is `/r/block-scan-scan-board.json`. |
