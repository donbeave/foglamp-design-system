Embedded Scan Board renders the scan result for the `foglamp` fixture. The story wraps the board in ScanFaviconProvider and resolves favicons from local story fixtures.

<story.WithControl />

## Package entry

`@foglamp/design-system/blocks/scan/embed-board` exports this block. The interactive preview above comes from `apps/docs/src/stories/blocks/embed-board-block.story.tsx`.

## API reference

| Entry | Contract |
| --- | --- |
| Story arguments | `slug: string`; initial values are `slug: 'foglamp'` |
| Fixture and callback wiring | The story exposes `slug` and supplies the scan fixture as `data`. Mount `EmbedBoard` under `ScanFaviconProvider` and provide a `ScanData` value plus the result slug. |
| Registry item | `block-scan-embed-board`. The portal payload is `/r/block-scan-embed-board.json`. |
