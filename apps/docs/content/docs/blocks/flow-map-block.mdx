Flow Map lays out the scan graph in a chosen direction. The story supplies the scan graph fixture and resolves its favicons through ScanFaviconProvider.

<story.WithControl />

## Package entry

`@foglamp/design-system/blocks/scan/flow-map` exports this block. The interactive preview above comes from `apps/docs/src/stories/blocks/flow-map-block.story.tsx`.

## API reference

| Entry | Contract |
| --- | --- |
| Story arguments | `direction: 'RIGHT' | 'DOWN'`; initial values are `direction: 'RIGHT'` |
| Fixture and callback wiring | The story exposes `direction` (`RIGHT` or `DOWN`). The source component receives the fixture graph and `focusKinds={null}`. For application data, supply a graph and an optional `NodeKind[]` focus filter under the favicon provider. |
| Registry item | `block-scan-flow-map`. The portal payload is `/r/block-scan-flow-map.json`. |
