## Public API

| Export | Prop | Type | Description |
| :--- | :--- | :--- | :--- |
| `OnboardingPanelBlock` | `apiKey?` | `string \| null` | Plaintext project API key injected into the onboarding snippet. |
|  | `prompt?` | `string` | Onboarding or instrumentation prompt copied by the CTA button. |
|  | `docsUrl?` | `string` | Documentation URL linked from the onboarding panel. |
|  | `onPromptCopied?` | `() => void` | Callback fired after the prompt is copied to the clipboard. |

## Usage

```tsx
import {
  OnboardingPanelBlock,
} from "@tailrocks/framerock/blocks/auth/onboarding-panel";

export function OnboardingPanelExample({
  apiKey = 'fr_demo_1234567890',
}: {
  apiKey?: string;
} = {}) {
  return (
    <OnboardingPanelBlock apiKey={apiKey} onPromptCopied={() => {}} />
  );
}
```
