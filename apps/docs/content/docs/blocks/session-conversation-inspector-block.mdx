## Package entry

`@foglamp/design-system/blocks/dashboard/session-conversation-inspector-block` exports this block. The interactive preview above comes from `apps/docs/src/stories/blocks/session-conversation-inspector-block.story.tsx`.

## API reference

| Entry | Contract |
| --- | --- |
| Story arguments | `sessionId: string`, `isLoading: boolean`; initial values are `sessionId: 'ses_a91f', isLoading: false` |
| Fixture and callback wiring | The story exposes `sessionId` and `isLoading`. The component accepts optional session data or `null`; the story uses the source default data. |
| Registry item | `block-dashboard-session-conversation-inspector`. The portal payload is `/r/block-dashboard-session-conversation-inspector.json`. |
