TraceGraph is the graph entry in `FIGURES.traces`. The story selects it with `FigureVariant`; the selected figure itself takes no props.

<story.WithControl />

## Selection and rendering

| Field | Value |
| --- | --- |
| Section | `traces` |
| Variant ID | `graph` |
| Source component | `TraceGraph` in `blocks/marketing/figures/figures-traces.tsx` |
| Component props | None |
| Registry item | `figure-traces-graph` |

The story uses the exact section and variant above. `FigureVariant` lazy-loads the matching source figure, wraps it in `FigureReveal`, and shows a reserved-height fallback while the module loads. The reveal choreography starts when the figure enters view. Figure content uses the source module’s local demo data.

The story is `apps/docs/src/stories/figures/traces-graph.story.tsx`. The registry route is `/r/figure-traces-graph.json` on the portal origin.
