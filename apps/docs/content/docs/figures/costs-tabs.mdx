CostTabs is the tabs entry in `FIGURES.costs`. The story selects it with `FigureVariant`; the selected figure itself takes no props.

<story.WithControl />

## Selection and rendering

| Field | Value |
| --- | --- |
| Section | `costs` |
| Variant ID | `tabs` |
| Source component | `CostTabs` in `blocks/marketing/figures/figures-costs.tsx` |
| Component props | None |
| Registry item | `figure-costs-tabs` |

The story uses the exact section and variant above. `FigureVariant` lazy-loads the matching source figure, wraps it in `FigureReveal`, and shows a reserved-height fallback while the module loads. The reveal choreography starts when the figure enters view. Figure content uses the source module’s local demo data.

The story is `apps/docs/src/stories/figures/costs-tabs.story.tsx`. The registry route is `/r/figure-costs-tabs.json` on the portal origin.
