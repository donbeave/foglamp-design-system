## Selection and rendering

| Field | Value |
| --- | --- |
| Section | `costs` |
| Variant ID | `backdrop` |
| Source component | `CostBackdrop` in `blocks/marketing/figures/figures-costs.tsx` |
| Component props | None |
| Registry item | `figure-costs-backdrop` |

The story uses the exact section and variant above. `FigureVariant` lazy-loads the matching source figure, wraps it in `FigureReveal`, and shows a reserved-height fallback while the module loads. The reveal choreography starts when the figure enters view. Figure content uses the source module’s local demo data.

## Usage

```tsx
import {
  FigureVariant,
} from "@tailrocks/framerock/blocks/marketing/figures/figure-picker";

export function CostsBackdropFigureExample() {
  return <FigureVariant section="costs" variantId="backdrop" />;
}
```
