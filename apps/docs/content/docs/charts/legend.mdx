## Requirements

The legend variant selects its indicator style. Set `isClickable` when selecting a legend item should change the active series.

## Source and registry

The interactive example comes from [`src/stories/charts/legend.story.tsx`](../../../src/stories/charts/legend.story.tsx). The story registry item is `chart-evilcharts-ui-legend` in [`public/r/story-items.json`](../../../public/r/story-items.json), with its [registry payload](../../../public/r/chart-evilcharts-ui-legend.json). The story panel builds an install command from the current portal origin. For local development, run `npx shadcn@latest add http://localhost:3000/r/chart-evilcharts-ui-legend.json` while the portal is running. The design-system package is not claimed to be published to npm.
