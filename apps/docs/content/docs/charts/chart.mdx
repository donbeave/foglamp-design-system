## Requirements

`ChartContainer` validates light and dark color definitions in `config` and exposes them through chart context. Render series and axes inside the chart container.

The shared container is exported from `@foglamp/design-system/charts/evilcharts/ui/chart` as `ChartContainer`. It requires a measurable width and height from the parent or its responsive sizing props.

| `ChartContainer` prop | Type | Meaning |
| :--- | :--- | :--- |
| `config` | `ChartConfig` | Series labels and at least one light or dark color array for each configured series. |
| `children` | `ReactNode` | Recharts axes, grid, tooltip, and series. |
| `footer` | `ReactNode` | Optional content below the responsive plot, such as `EvilBrush`. |
| `isUpdating` | `boolean` | Dims the plot while refreshed data arrives. Defaults to `false`. |
| `height` | `string \| number` | Responsive plot height. |
| `width` | `string \| number` | Responsive plot width. |
| `aspect` | `number` | Responsive plot aspect ratio. |
| `debounce` | `number` | Resize observer debounce in milliseconds. Defaults to `100`. |

Each `ChartConfig` entry accepts an optional `label`, optional icon component, and `colors`. The `colors` object must include `light`, `dark`, or both. Each value is an array of colors used by the series.

```ts
const config = {
  requests: {
    label: "Requests",
    colors: { light: ["#0090fd"], dark: ["#55b3ff"] },
  },
} satisfies ChartConfig;
```

## Source and registry

The interactive example comes from [`src/stories/charts/chart.story.tsx`](../../../src/stories/charts/chart.story.tsx). The story registry item is `chart-evilcharts-ui-chart` in [`public/r/story-items.json`](../../../public/r/story-items.json), with its [registry payload](../../../public/r/chart-evilcharts-ui-chart.json). The story panel builds an install command from the current portal origin. For local development, run `npx shadcn@latest add http://localhost:3000/r/chart-evilcharts-ui-chart.json` while the portal is running. The design-system package is not claimed to be published to npm.
