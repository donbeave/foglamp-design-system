## Requirements

`useZoomDrag` takes `data`, `xDataKey`, `onZoomSelect`, and optional `disabled`. It returns `enabled`, `overlay`, `suppressClickRef`, and chart mouse `handlers`. The callback receives the selected x values as strings. A drag across at least two buckets selects a range; a press in one bucket stays a click. The area, line, and bar charts wire this hook when given `xDataKey` and `onZoomSelect`.

`useZoomDrag` is also exported from `@foglamp/design-system/charts/evilcharts/ui/zoom`.

| Hook input | Type | Meaning |
| :--- | :--- | :--- |
| `data` | `readonly Record<string, unknown>[]` | Rows currently rendered by the chart. |
| `xDataKey` | `string \| undefined` | Field whose values identify the selected range endpoints. |
| `onZoomSelect` | `(startX: string, endX: string) => void` | Receives the selected endpoint values. The hook is inactive when omitted. |
| `disabled` | `boolean` | Disables drag selection. Defaults to `false`. |

The hook returns `enabled`, a Recharts `overlay`, `suppressClickRef`, and mouse handlers for pointer-down, move, up, and leave. The line, area, and bar charts already connect these handlers when you pass their zoom props.

## Source and registry

The interactive example comes from [`src/stories/charts/zoom.story.tsx`](../../../src/stories/charts/zoom.story.tsx). The story registry item is `chart-evilcharts-ui-zoom` in [`public/r/story-items.json`](../../../public/r/story-items.json), with its [registry payload](../../../public/r/chart-evilcharts-ui-zoom.json). The story panel builds an install command from the current portal origin. For local development, run `npx shadcn@latest add http://localhost:3000/r/chart-evilcharts-ui-zoom.json` while the portal is running. The design-system package is not claimed to be published to npm.
