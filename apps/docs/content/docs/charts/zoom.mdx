## Public API

| Export | Parameter / Return | Type | Description |
| :--- | :--- | :--- | :--- |
| `useZoomDrag` | `data` | `readonly Record<string, unknown>[]` | Rows currently rendered by the chart. |
| | `xDataKey` | `string \| undefined` | Field in `data` whose values identify the selected range endpoints. |
| | `onZoomSelect` | `ZoomSelectHandler \| undefined` | Callback invoked with `(startX, endX)` when a drag selection completes. |
| | `disabled?` | `boolean` | Disables drag selection (for example while loading skeletons are shown). |
| | `returns` | `{ enabled, overlay, suppressClickRef, handlers }` | Recharts `<ReferenceArea />` overlay and chart mouse event handlers. |
| `ZoomSelectHandler` | `type` | `(startX: string, endX: string) => void` | Callback signature receiving the ordered start and end x-axis bucket values. |

## Requirements

`useZoomDrag` takes `data`, `xDataKey`, `onZoomSelect`, and optional `disabled`. It returns `enabled`, `overlay`, `suppressClickRef`, and chart mouse `handlers`. The callback receives the selected x values as strings. A drag across at least two buckets selects a range; a press in one bucket stays a click. The area, line, and bar charts wire this hook when given `xDataKey` and `onZoomSelect`.

`useZoomDrag` is also exported from `@tailrocks/framerock/charts/evilcharts/ui/zoom`.

## Usage

```tsx
import { useState } from "react";
import {
  EvilLineChart,
  Line,
  Grid,
  Tooltip,
  XAxis,
  YAxis,
} from "@tailrocks/framerock/charts/evilcharts/charts/line-chart";
import type { ChartConfig } from "@tailrocks/framerock/charts/evilcharts/ui/chart";

const observabilityConfig = {
  requests: { label: "Requests", colors: { light: ["#6d5efc"], dark: ["#a59bff"] } },
  errors: { label: "Errors", colors: { light: ["#e05d71"], dark: ["#ff8292"] } },
  latency: { label: "Latency", colors: { light: ["#19a98c"], dark: ["#54d9b5"] } },
} satisfies ChartConfig;

const observabilityData = [
  { day: "Mon", requests: 116, errors: 9, latency: 178 },
  { day: "Tue", requests: 132, errors: 12, latency: 194 },
  { day: "Wed", requests: 124, errors: 7, latency: 169 },
  { day: "Thu", requests: 158, errors: 15, latency: 218 },
  { day: "Fri", requests: 147, errors: 11, latency: 203 },
];

export function ZoomExample({
  showBrush = true,
}: {
  showBrush?: boolean;
} = {}) {
  const [range, setRange] = useState<string | null>(null);
  return (
    <>
      <div
      className="mb-2 flex min-h-6 items-center justify-between text-xs text-muted-foreground"
    >
      <span>Drag across plot buckets to zoom · double-click to reset</span>
      <span aria-live="polite">
        {range ?? 'Full reporting window'}
      </span>
    </div>
      <EvilLineChart
      config={observabilityConfig}
      data={observabilityData}
      className="h-[300px]"
      animationType="none"
      curveType="monotone"
      xDataKey="day"
      showBrush={showBrush}
      onZoomSelect={(start, end) => setRange(`${start} → ${end}`)}
      onZoomReset={() => setRange(null)}
    >
      <Grid />
      <XAxis dataKey="day" />
      <YAxis width={32} />
      <Tooltip />
      <Line dataKey="requests" />
      <Line dataKey="errors" />
    </EvilLineChart>
    </>
  );
}
```
