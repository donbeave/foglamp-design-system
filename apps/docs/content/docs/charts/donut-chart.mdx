## Public API

The table lists public exports used by this story. Prop names and TypeScript types come from the design-system source.

| Export | Prop | Type | Meaning |
| :--- | :--- | :--- | :--- |
| `EvilDonutChart` | `config` | `ChartConfig` | Labels and light/dark colors keyed by data series. |
|  | `data` | `DonutSlice[]` | Rows consumed by the component or visualization. |
|  | `className` | `string \| undefined` | Adds a class to the rendered root element. |
|  | `centerLabel` | `ReactNode` | Text displayed in the center of the donut. |
|  | `centerSubLabel` | `ReactNode` | Supporting text below the center label. |
|  | `showLegend` | `boolean \| undefined` | Shows the donut chart legend. |
|  | `legendVariant` | `ChartLegendVariant \| undefined` | Selects the legend indicator shape. |
|  | `tooltipVariant` | `TooltipVariant \| undefined` | Selects the tooltip appearance. |
|  | `valueFormatter` | `((value: ValueType, key: string) => ReactNode) \| undefined` | Formats each plotted value for display. |
|  | `isLoading` | `boolean \| undefined` | Shows the component loading state. |

## Requirements

`DonutSlice` contains a `key` and numeric `value`. The `config` object maps each key to a `label` and light/dark color arrays. Give the chart parent a height so `ResponsiveContainer` can measure it.
