## API and props

The table lists values exported from `@tailrocks/framerock/ui/command`. The declared type comes from the component source.

| Export | Declared props or type | Role |
| --- | --- | --- |
| `Command` | `React.ComponentProps<typeof CommandPrimitive>` | Command list root backed by cmdk. |
| `CommandDialog` | `Omit<React.ComponentProps<typeof Dialog>, "children"> & { title?: string; description?: string; className?: string; showCloseButton?: boolean; children: React.ReactNode; }` | Wraps the command list in the project Dialog composition. |
| `CommandEmpty` | `React.ComponentProps<typeof CommandPrimitive.Empty>` | Empty-result content. |
| `CommandGroup` | `React.ComponentProps<typeof CommandPrimitive.Group>` | Groups related entries. |
| `CommandInput` | `React.ComponentProps<typeof CommandPrimitive.Input>` | Input control for the composition. |
| `CommandItem` | `React.ComponentProps<typeof CommandPrimitive.Item>` | One selectable or repeated entry. |
| `CommandList` | `React.ComponentProps<typeof CommandPrimitive.List>` | List container for related entries. |
| `CommandSeparator` | `React.ComponentProps<typeof CommandPrimitive.Separator>` | Visual or semantic divider. |
| `CommandShortcut` | `React.ComponentProps<"span">` | Keyboard shortcut label. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `CommandDialog.title` | `string` | Defaults to `Command Palette`. |
| `CommandDialog.description` | `string` | Defaults to `Search for a command to run...`. |
| `CommandDialog.showCloseButton` | `boolean` | Defaults to `false`. |
| `CommandDialog.children` | `React.ReactNode` | Required command content. |

## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { Command, CommandInput, CommandList, CommandEmpty, CommandGroup, CommandItem, CommandShortcut } from '@tailrocks/framerock/ui/command';

function CommandExample({ placeholder = 'Search commands…' }: { placeholder?: string }) { return <Command className="w-full max-w-md rounded-lg shadow-(--custom-shadow)"><CommandInput placeholder={placeholder} /><CommandList><CommandEmpty>No matching commands.</CommandEmpty><CommandGroup heading="Workspace"><CommandItem><span aria-hidden="true">⌁</span>Open observability<CommandShortcut>⌘1</CommandShortcut></CommandItem><CommandItem><span aria-hidden="true">⌕</span>Search traces<CommandShortcut>⌘K</CommandShortcut></CommandItem></CommandGroup><CommandGroup heading="Manage"><CommandItem><span aria-hidden="true">◎</span>Team settings</CommandItem><CommandItem><span aria-hidden="true">⚙</span>Preferences</CommandItem></CommandGroup></CommandList></Command>; }
```

## Registry item

The story panel resolves this component as registry item `ui-command`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-command.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-command.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@tailrocks/framerock/ui/command`. The workspace declares `@tailrocks/framerock` as a package; these docs do not claim npm publication.
