# Tooltip

Base UI tooltip root, trigger, popup, and provider. Popup placement is configurable, and provider delay defaults to zero milliseconds.

## Live preview

<story.WithControl />

## API and props

The table lists values exported from `@foglamp/design-system/ui/tooltip`. The declared type comes from the component source.

| Export | Declared props or type | Role |
| --- | --- | --- |
| `Tooltip` | `TooltipPrimitive.Root.Props` | Tooltip state root. |
| `TooltipContent` | `TooltipPrimitive.Popup.Props & Pick< TooltipPrimitive.Positioner.Props, "align" \| "alignOffset" \| "side" \| "sideOffset" >` | Positioned tooltip popup. |
| `TooltipProvider` | `TooltipPrimitive.Provider.Props` | Provider for tooltip delay and shared state. |
| `TooltipTrigger` | `TooltipPrimitive.Trigger.Props` | Element that triggers the tooltip. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `TooltipProvider.delay` | `number` | Open delay in milliseconds. Defaults to `0`. |
| `TooltipContent.side` | `Base UI positioner side` | Defaults to `top`. |
| `TooltipContent.sideOffset` | `number` | Defaults to `4`. |
| `TooltipContent.align` | `Base UI positioner alignment` | Defaults to `center`. |
| `TooltipContent.alignOffset` | `number` | Defaults to `0`. |

## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { useState } from "react";

import { TooltipProvider, Tooltip, TooltipTrigger, TooltipContent } from "@foglamp/design-system/ui/tooltip";

type Args = { variant: 'default' };

function TooltipStory({ args }: { args: Args }) {

  return <div className="flex min-h-24 w-full items-center justify-center p-4"><TooltipProvider><div className="flex items-center gap-2"><span className="text-sm">Sampling rate</span><Tooltip><TooltipTrigger aria-label="About sampling">ⓘ</TooltipTrigger><TooltipContent>Percentage of requests captured for analysis.</TooltipContent></Tooltip></div></TooltipProvider></div>;
}
```

## Registry item

The story panel resolves this component as registry item `ui-tooltip`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-tooltip.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-tooltip.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@foglamp/design-system/ui/tooltip`. The workspace declares `@foglamp/design-system` as a package; these docs do not claim npm publication.
