## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { HoverCard, HoverCardTrigger, HoverCardContent } from '@tailrocks/framerock/ui/hover-card';

function HoverCardExample({ service = 'checkout-api' }: { service?: string }) { return <HoverCard><HoverCardTrigger className="font-medium underline decoration-dotted underline-offset-4">{service}</HoverCardTrigger><HoverCardContent><p className="font-medium">{service}</p><p className="mt-1 text-xs text-muted-foreground">Production · us-east-1</p><div className="mt-3 grid grid-cols-2 gap-2 text-xs"><span className="text-muted-foreground">Requests</span><span>2.4k / min</span><span className="text-muted-foreground">p95 latency</span><span>482 ms</span></div></HoverCardContent></HoverCard>; }
```

## Registry item

The story panel resolves this component as registry item `ui-hover-card`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-hover-card.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-hover-card.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@tailrocks/framerock/ui/hover-card`. The workspace declares `@tailrocks/framerock` as a package; these docs do not claim npm publication.
