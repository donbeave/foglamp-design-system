## API and props


| Export | Declared props or type | Role |
| --- | --- | --- |
| `HoverCard` | `PreviewCardPrimitive.Root.Props` | Preview-card state root. |
| `HoverCardContent` | `PreviewCardPrimitive.Popup.Props & Pick< PreviewCardPrimitive.Positioner.Props, "align" \| "alignOffset" \| "side" \| "sideOffset" >` | Contains the associated popup or panel content. |
| `HoverCardTrigger` | `PreviewCardPrimitive.Trigger.Props` | Opens or toggles the associated popup or panel. |

## Additional props

The exports forward the props declared by their source component types. The public type for each export appears in the table above.

## Usage

```tsx
import {
  HoverCard,
  HoverCardTrigger,
  HoverCardContent,
} from "@tailrocks/framerock/ui/hover-card";

export function HoverCardExample({
  service = 'checkout-api',
}: {
  service?: string;
} = {}) {
  return (
    <HoverCard>
      <HoverCardTrigger
        className="font-medium underline decoration-dotted underline-offset-4"
      >
        {service}
      </HoverCardTrigger>
      <HoverCardContent>
        <p className="font-medium">
          {service}
        </p>
        <p className="mt-1 text-xs text-muted-foreground">
          Production · us-east-1
        </p>
        <div className="mt-3 grid grid-cols-2 gap-2 text-xs">
          <span className="text-muted-foreground">Requests</span>
          <span>2.4k / min</span>
          <span className="text-muted-foreground">p95 latency</span>
          <span>482 ms</span>
        </div>
      </HoverCardContent>
    </HoverCard>
  );
}
```
