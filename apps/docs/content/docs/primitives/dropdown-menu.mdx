## API and props

The table lists values exported from `@tailrocks/framerock/ui/dropdown-menu`. The declared type comes from the component source.

| Export | Declared props or type | Role |
| --- | --- | --- |
| `DropdownMenu` | `MenuPrimitive.Root.Props` | Positioned menu state root. |
| `DropdownMenuCheckboxItem` | `MenuPrimitive.CheckboxItem.Props & { inset?: boolean; }` | Menu item with checkbox state. |
| `DropdownMenuContent` | `MenuPrimitive.Popup.Props & Pick< MenuPrimitive.Positioner.Props, "align" \| "alignOffset" \| "side" \| "sideOffset" >` | Positioned menu popup. |
| `DropdownMenuGroup` | `MenuPrimitive.Group.Props` | Groups related entries. |
| `DropdownMenuItem` | `MenuPrimitive.Item.Props & { inset?: boolean; variant?: "default" \| "destructive"; }` | One selectable menu command. |
| `DropdownMenuLabel` | `React.ComponentProps<"div"> & { inset?: boolean; }` | Label for the associated control or group. |
| `DropdownMenuPortal` | `MenuPrimitive.Portal.Props` | Renders overlay content in a portal. |
| `DropdownMenuRadioGroup` | `MenuPrimitive.RadioGroup.Props` | Groups mutually exclusive menu items. |
| `DropdownMenuRadioItem` | `MenuPrimitive.RadioItem.Props & { inset?: boolean; }` | Menu item with radio state. |
| `DropdownMenuSeparator` | `MenuPrimitive.Separator.Props` | Visual or semantic divider. |
| `DropdownMenuShortcut` | `React.ComponentProps<"span">` | Keyboard shortcut label. |
| `DropdownMenuSub` | `MenuPrimitive.SubmenuRoot.Props` | Declares a nested submenu. |
| `DropdownMenuSubContent` | `React.ComponentProps<typeof DropdownMenuContent>` | Contains nested submenu entries. |
| `DropdownMenuSubTrigger` | `MenuPrimitive.SubmenuTrigger.Props & { inset?: boolean; }` | Opens a nested submenu. |
| `DropdownMenuTrigger` | `MenuPrimitive.Trigger.Props` | Control that opens the menu. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `DropdownMenuItem.inset` | `boolean` | Indent the item. |
| `DropdownMenuItem.variant` | `default \| destructive` | Defaults to `default`. |

## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { DropdownMenu, DropdownMenuTrigger, DropdownMenuContent, DropdownMenuLabel, DropdownMenuItem, DropdownMenuSeparator, DropdownMenuShortcut, DropdownMenuCheckboxItem } from '@tailrocks/framerock/ui/dropdown-menu';

import { Button } from '@tailrocks/framerock/ui/button';

function DropdownMenuExample({ label = 'Run actions' }: { label?: string }) { return <DropdownMenu><DropdownMenuTrigger render={<Button variant="outline" />}>{label}</DropdownMenuTrigger><DropdownMenuContent align="start"><DropdownMenuLabel>Evaluation</DropdownMenuLabel><DropdownMenuItem>Open report<DropdownMenuShortcut>↵</DropdownMenuShortcut></DropdownMenuItem><DropdownMenuItem>Duplicate run</DropdownMenuItem><DropdownMenuCheckboxItem checked>Pin to workspace</DropdownMenuCheckboxItem><DropdownMenuSeparator /><DropdownMenuItem variant="destructive">Delete run</DropdownMenuItem></DropdownMenuContent></DropdownMenu>; }
```

## Registry item

The story panel resolves this component as registry item `ui-dropdown-menu`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-dropdown-menu.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-dropdown-menu.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@tailrocks/framerock/ui/dropdown-menu`. The workspace declares `@tailrocks/framerock` as a package; these docs do not claim npm publication.
