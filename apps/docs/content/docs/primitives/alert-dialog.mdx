# Alert Dialog

Modal confirmation flow with a backdrop, title, description, and action or cancel controls. Content size and cancel button styling are exposed by this wrapper.

## API and props

The table lists values exported from `@tailrocks/framerock/ui/alert-dialog`. The declared type comes from the component source.

| Export | Declared props or type | Role |
| --- | --- | --- |
| `AlertDialog` | `AlertDialogPrimitive.Root.Props` | Root for confirmation dialog state. |
| `AlertDialogAction` | `React.ComponentProps<typeof Button>` | Confirmation action button. |
| `AlertDialogCancel` | `AlertDialogPrimitive.Close.Props & Pick<React.ComponentProps<typeof Button>, "variant" \| "size">` | Cancel control for the confirmation dialog. |
| `AlertDialogContent` | `AlertDialogPrimitive.Popup.Props & { size?: "default" \| "sm"; }` | Popup body for the confirmation dialog. |
| `AlertDialogDescription` | `React.ComponentProps<typeof AlertDialogPrimitive.Description>` | Supporting text for the confirmation dialog. |
| `AlertDialogFooter` | `React.ComponentProps<"div">` | Footer slot for dialog actions. |
| `AlertDialogHeader` | `React.ComponentProps<"div">` | Header slot for dialog title and supporting text. |
| `AlertDialogMedia` | `React.ComponentProps<"div">` | Media slot for the confirmation dialog. |
| `AlertDialogOverlay` | `AlertDialogPrimitive.Backdrop.Props` | Backdrop behind the confirmation dialog. |
| `AlertDialogPortal` | `AlertDialogPrimitive.Portal.Props` | Renders the confirmation dialog in a portal. |
| `AlertDialogTitle` | `React.ComponentProps<typeof AlertDialogPrimitive.Title>` | Confirmation dialog title. |
| `AlertDialogTrigger` | `AlertDialogPrimitive.Trigger.Props` | Opens the confirmation dialog. |

## Additional props

The exports forward the props declared by their source component types. The public type for each export appears in the table above.

## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { AlertDialog, AlertDialogTrigger, AlertDialogContent, AlertDialogHeader, AlertDialogTitle, AlertDialogDescription, AlertDialogFooter, AlertDialogCancel, AlertDialogAction } from '@tailrocks/framerock/ui/alert-dialog';

import { Button } from '@tailrocks/framerock/ui/button';

function AlertDialogExample({ actionLabel = 'Delete run' }: { actionLabel?: string }) { return <AlertDialog><AlertDialogTrigger render={<Button variant="outline" />}>Remove evaluation</AlertDialogTrigger><AlertDialogContent><AlertDialogHeader><AlertDialogTitle>Delete this evaluation?</AlertDialogTitle><AlertDialogDescription>This permanently removes the evaluation and its score history.</AlertDialogDescription></AlertDialogHeader><AlertDialogFooter><AlertDialogCancel>Cancel</AlertDialogCancel><AlertDialogAction variant="destructive">{actionLabel}</AlertDialogAction></AlertDialogFooter></AlertDialogContent></AlertDialog>; }
```

## Registry item

The story panel resolves this component as registry item `ui-alert-dialog`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-alert-dialog.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-alert-dialog.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@tailrocks/framerock/ui/alert-dialog`. The workspace declares `@tailrocks/framerock` as a package; these docs do not claim npm publication.
