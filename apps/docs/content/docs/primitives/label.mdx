## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { useState } from "react";

import { Label } from "@tailrocks/framerock/ui/label";

type Args = { variant: 'default' };

function LabelStory({ args }: { args: Args }) {

  return <div className="flex min-h-24 w-full items-center justify-center p-4"><div className="grid max-w-sm gap-2"><Label htmlFor="workspace">Workspace name</Label><input id="workspace" className="h-9 rounded-md bg-background px-3 shadow-(--custom-shadow)" defaultValue="Production" /><p className="text-xs text-muted-foreground">Visible to your team.</p></div></div>;
}
```

## Registry item

The story panel resolves this component as registry item `ui-label`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-label.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-label.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@tailrocks/framerock/ui/label`. The workspace declares `@tailrocks/framerock` as a package; these docs do not claim npm publication.
