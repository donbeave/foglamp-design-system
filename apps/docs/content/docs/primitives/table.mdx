# Table

Semantic table composition with optional internal scrolling and sticky headers. Rows can opt into keyboard-accessible interaction, and cells accept start, center, or end alignment.

## API and props

The table lists values exported from `@tailrocks/framerock/ui/table`. The declared type comes from the component source.

| Export | Declared props or type | Role |
| --- | --- | --- |
| `Table` | `React.ComponentProps<"table"> & {  maxHeight?: number \| string;  stickyHeader?: boolean; }` | Semantic table with optional sticky header and internal scrolling. |
| `TableBody` | `React.ComponentProps<"tbody">` | Table body section containing data rows. |
| `TableCaption` | `React.ComponentProps<"caption">` | Caption that labels the table. |
| `TableCell` | `Omit<React.ComponentProps<"td">, "align"> & { align?: Align }` | Data cell with start, center, or end alignment. |
| `TableFooter` | `React.ComponentProps<"tfoot">` | Table footer section for summary or totals. |
| `TableHead` | `Omit<React.ComponentProps<"th">, "align"> & { align?: Align }` | Header cell with start, center, or end alignment. |
| `TableHeader` | `React.ComponentProps<"thead">` | Table head section containing header rows. |
| `TableRow` | `React.ComponentProps<"tr"> & {  interactive?: boolean; }` | Semantic row. Set interactive to enable the component’s keyboard and hover behavior. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `Table.maxHeight` | `number \| string` | Optional cap; the body scrolls internally when set. |
| `Table.stickyHeader` | `boolean` | Pins the header. Auto-enabled when `maxHeight` is set. |
| `TableRow.interactive` | `boolean` | Enables pointer and hover treatment plus Enter and Space activation. |
| `TableHead.align` | `start \| center \| end` | Header content alignment. |
| `TableCell.align` | `start \| center \| end` | Cell content alignment. |

## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { useState } from "react";

import { Table, TableHeader, TableBody, TableHead, TableRow, TableCell, TableCaption } from "@tailrocks/framerock/ui/table";

type Args = { variant: 'interactive' };

function TableStory({ args }: { args: Args }) {
  const [selected, setSelected] = useState("tr_002"); const rows = [{id:"tr_001",model:"gpt-4.1",latency:421},{id:"tr_002",model:"claude-sonnet",latency:876},{id:"tr_003",model:"o4-mini",latency:193}];
  return <div className="flex min-h-24 w-full items-center justify-center p-4"><div className="max-h-60 w-full overflow-auto rounded-md shadow-(--custom-shadow)"><Table><TableCaption>Recent model requests</TableCaption><TableHeader className="sticky top-0 bg-background"><TableRow><TableHead>Request</TableHead><TableHead>Model</TableHead><TableHead className="text-right">Latency</TableHead></TableRow></TableHeader><TableBody>{rows.map(row => <TableRow key={row.id} onClick={() => setSelected(row.id)} data-state={selected === row.id ? "selected" : undefined} className="cursor-pointer"><TableCell>{row.id}</TableCell><TableCell>{row.model}</TableCell><TableCell className="text-right">{row.latency} ms</TableCell></TableRow>)}</TableBody></Table></div></div>;
}
```

## Registry item

The story panel resolves this component as registry item `ui-table`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-table.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-table.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@tailrocks/framerock/ui/table`. The workspace declares `@tailrocks/framerock` as a package; these docs do not claim npm publication.
