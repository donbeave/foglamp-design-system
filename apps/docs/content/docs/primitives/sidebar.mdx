## API and props

The table lists values exported from `@tailrocks/framerock/ui/sidebar`. The declared type comes from the component source.

| Export | Declared props or type | Role |
| --- | --- | --- |
| `Sidebar` | `React.ComponentProps<"div"> & { side?: "left" \| "right"; variant?: "sidebar" \| "floating" \| "inset"; collapsible?: "offcanvas" \| "icon" \| "none"; }` | Sidebar layout container. |
| `SidebarContent` | `React.ComponentProps<"div">` | Contains the associated popup or panel content. |
| `SidebarFooter` | `React.ComponentProps<"div">` | Footer slot for actions or supporting content. |
| `SidebarGroup` | `React.ComponentProps<"div">` | Groups related entries. |
| `SidebarGroupAction` | `useRender.ComponentProps<"button"> & React.ComponentProps<"button">` | Action control aligned with a sidebar group label. |
| `SidebarGroupContent` | `React.ComponentProps<"div">` | Content area inside a sidebar group. |
| `SidebarGroupLabel` | `useRender.ComponentProps<"div"> & React.ComponentProps<"div">` | Label for the associated control or group. |
| `SidebarHeader` | `React.ComponentProps<"div">` | Header slot for title and supporting content. |
| `SidebarInput` | `React.ComponentProps<typeof Input>` | Input control for the composition. |
| `SidebarInset` | `React.ComponentProps<"main">` | Main page area positioned beside the sidebar. |
| `SidebarMenu` | `React.ComponentProps<"ul">` | List container for sidebar menu rows. |
| `SidebarMenuAction` | `useRender.ComponentProps<"button"> & React.ComponentProps<"button"> & { showOnHover?: boolean; }` | Action control aligned with a sidebar menu row. |
| `SidebarMenuBadge` | `React.ComponentProps<"div">` | Badge aligned with a sidebar menu row. |
| `SidebarMenuButton` | `useRender.ComponentProps<"button"> & React.ComponentProps<"button"> & { isActive?: boolean; tooltip?: string \| React.ComponentProps<typeof TooltipContent>; } & VariantProps<typeof sidebarMenuButtonVariants>` | Sidebar menu link or button with active, variant, size, and tooltip options. |
| `SidebarMenuItem` | `React.ComponentProps<"li">` | List item that contains a sidebar menu row. |
| `SidebarMenuSkeleton` | `React.ComponentProps<"div"> & { showIcon?: boolean; }` | Placeholder for a sidebar menu row. |
| `SidebarMenuSub` | `React.ComponentProps<"ul">` | Nested sidebar menu list. |

| `useSidebar` | `Exported component or value` | Reads the sidebar state and controls. |

## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { useState } from "react";

import { SidebarProvider, Sidebar, SidebarHeader, SidebarContent, SidebarGroup, SidebarGroupLabel, SidebarMenu, SidebarMenuItem, SidebarMenuButton, SidebarInset, SidebarTrigger } from "@tailrocks/framerock/ui/sidebar";

type Args = { variant: 'expanded' };

function SidebarStory({ args }: { args: Args }) {

  return <div className="flex min-h-24 w-full items-center justify-center p-4"><SidebarProvider defaultOpen><Sidebar><SidebarHeader className="p-3 font-semibold">Foglamp</SidebarHeader><SidebarContent><SidebarGroup><SidebarGroupLabel>Workspace</SidebarGroupLabel><SidebarMenu><SidebarMenuItem><SidebarMenuButton isActive>Overview</SidebarMenuButton></SidebarMenuItem><SidebarMenuItem><SidebarMenuButton>Traces</SidebarMenuButton></SidebarMenuItem><SidebarMenuItem><SidebarMenuButton>Evaluations</SidebarMenuButton></SidebarMenuItem></SidebarMenu></SidebarGroup></SidebarContent></Sidebar><SidebarInset className="min-h-48"><header className="flex items-center gap-3 border-b p-3"><SidebarTrigger /><span className="text-sm font-medium">Overview</span></header><div className="p-4 text-sm text-muted-foreground">Workspace navigation with responsive collapse behavior.</div></SidebarInset></SidebarProvider></div>;
}
```

## Registry item

The story panel resolves this component as registry item `ui-sidebar`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-sidebar.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-sidebar.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@tailrocks/framerock/ui/sidebar`. The workspace declares `@tailrocks/framerock` as a package; these docs do not claim npm publication.
