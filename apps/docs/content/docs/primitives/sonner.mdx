## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { useState } from "react";

import { Toaster } from "@tailrocks/framerock/ui/sonner";

type Args = { variant: 'default' };

function SonnerStory({ args }: { args: Args }) {

  return <div className="flex min-h-24 w-full items-center justify-center p-4"><div className="flex flex-wrap gap-2"><button className="rounded-md bg-primary px-3 py-2 text-primary-foreground" onClick={() => document.dispatchEvent(new CustomEvent("foglamp:toast", { detail: { type: "success", message: "Evaluation passed" } }))}>Success toast</button><button className="rounded-md px-3 py-2 shadow-(--custom-shadow)" onClick={() => document.dispatchEvent(new CustomEvent("foglamp:toast", { detail: { type: "error", message: "Export failed" } }))}>Error toast</button><Toaster /></div></div>;
}
```

## Registry item

The story panel resolves this component as registry item `ui-sonner`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-sonner.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-sonner.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@tailrocks/framerock/ui/sonner`. The workspace declares `@tailrocks/framerock` as a package; these docs do not claim npm publication.
