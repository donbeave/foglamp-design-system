# Button

Action control with seven visual variants and eight sizes. It preserves Base UI button polymorphism through the render prop and infers native-button behavior when render is absent.

## API and props

The table lists values exported from `@tailrocks/framerock/ui/button`. The declared type comes from the component source.

| Export | Declared props or type | Role |
| --- | --- | --- |
| `Button` | `ButtonPrimitive.Props & VariantProps<typeof buttonVariants>` | Action button with visual variants and sizes. |
| `buttonVariants` | `Class variance recipe` | Exports the button class recipe. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `Button.variant` | `default \| outline \| secondary \| ghost \| ghost-destructive \| destructive \| link` | Defaults to `default`. |
| `Button.size` | `xs \| sm \| default \| lg \| icon \| icon-xs \| icon-sm \| icon-lg` | Defaults to `default`. |
| `Button.nativeButton` | `Base UI button prop` | If omitted, true when `render` is absent and false when `render` is supplied. |

## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { Button } from '@tailrocks/framerock/ui/button';

function ButtonExample({ variant = 'default', size = 'default', disabled = false }: { variant?: 'default' | 'secondary' | 'outline' | 'destructive' | 'ghost' | 'link'; size?: 'default' | 'sm' | 'lg'; disabled?: boolean }) { return <div className="flex flex-wrap items-center gap-3"><Button variant={variant} size={size} disabled={disabled}>Run evaluation</Button><Button variant="outline">View trace</Button><Button variant="ghost">More options</Button><Button render={<a href="/traces" />}>View traces</Button></div>; }
```

## Registry item

The story panel resolves this component as registry item `ui-button`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-button.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-button.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@tailrocks/framerock/ui/button`. The workspace declares `@tailrocks/framerock` as a package; these docs do not claim npm publication.
