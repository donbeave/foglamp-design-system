# Collapsible

Controlled or uncontrolled disclosure root with separate trigger and panel exports.

## Live preview

<story.WithControl />

## API and props

The table lists values exported from `@foglamp/design-system/ui/collapsible`. The declared type comes from the component source.

| Export | Declared props or type | Role |
| --- | --- | --- |
| `Collapsible` | `CollapsiblePrimitive.Root.Props` | Disclosure root for trigger and panel state. |
| `CollapsibleContent` | `CollapsiblePrimitive.Panel.Props` | Contains the associated popup or panel content. |
| `CollapsibleTrigger` | `CollapsiblePrimitive.Trigger.Props` | Opens or toggles the associated popup or panel. |

## Additional props

The exports forward the props declared by their source component types. The public type for each export appears in the table above.

## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { useState } from 'react';

import { Collapsible, CollapsibleTrigger, CollapsibleContent } from '@foglamp/design-system/ui/collapsible';

import { Button } from '@foglamp/design-system/ui/button';

function CollapsibleExample({ defaultOpen = true }: { defaultOpen?: boolean }) { const [open, setOpen] = useState(defaultOpen); return <Collapsible open={open} onOpenChange={setOpen} className="w-full max-w-md rounded-lg shadow-(--custom-shadow) p-4"><div className="flex items-center justify-between"><div><p className="font-medium">Evaluator details</p><p className="text-sm text-muted-foreground">3 configuration values</p></div><CollapsibleTrigger render={<Button variant="outline" size="sm" />}>{open ? 'Hide' : 'Show'}</CollapsibleTrigger></div><CollapsibleContent><dl className="mt-4 grid grid-cols-2 gap-2 text-sm"><dt className="text-muted-foreground">Model</dt><dd>gpt-4.1</dd><dt className="text-muted-foreground">Temperature</dt><dd>0.2</dd><dt className="text-muted-foreground">Max tokens</dt><dd>2048</dd></dl></CollapsibleContent></Collapsible>; }
```

## Registry item

The story panel resolves this component as registry item `ui-collapsible`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-collapsible.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-collapsible.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@foglamp/design-system/ui/collapsible`. The workspace declares `@foglamp/design-system` as a package; these docs do not claim npm publication.
