# Switch

Base UI switch with default and compact sizes and root state props.

## Live preview

<story.WithControl />

## API and props

The table lists values exported from `@foglamp/design-system/ui/switch`. The declared type comes from the component source.

| Export | Declared props or type | Role |
| --- | --- | --- |
| `Switch` | `SwitchPrimitive.Root.Props & { size?: "sm" \| "default"; }` | Switch input root. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `Switch.size` | `sm \| default` | Defaults to `default`. |

## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { useState } from "react";

import { Switch } from "@foglamp/design-system/ui/switch";

import { Label } from "@foglamp/design-system/ui/label";

type Args = { enabled: true };

function SwitchStory({ args }: { args: Args }) {
  const [enabled, setEnabled] = useState(true);
  return <div className="flex min-h-24 w-full items-center justify-center p-4"><div className="flex w-full max-w-sm items-center justify-between gap-4"><div><Label htmlFor="live-refresh">Live refresh</Label><p className="text-xs text-muted-foreground">Update this dashboard automatically.</p></div><Switch id="live-refresh" checked={enabled} onCheckedChange={setEnabled} /></div></div>;
}
```

## Registry item

The story panel resolves this component as registry item `ui-switch`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-switch.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-switch.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@foglamp/design-system/ui/switch`. The workspace declares `@foglamp/design-system` as a package; these docs do not claim npm publication.
