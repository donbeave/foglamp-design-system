# Input Otp

OTP input composition with groups, indexed slots, and separators. The root adds a class for the OTP input package container.

## Live preview

<story.WithControl />

## API and props

The table lists values exported from `@foglamp/design-system/ui/input-otp`. The declared type comes from the component source.

| Export | Declared props or type | Role |
| --- | --- | --- |
| `InputOTP` | `React.ComponentProps<typeof OTPInput> & { containerClassName?: string; }` | OTP input root. |
| `InputOTPGroup` | `React.ComponentProps<"div">` | Groups related entries. |
| `InputOTPSeparator` | `React.ComponentProps<"div">` | Visual or semantic divider. |
| `InputOTPSlot` | `React.ComponentProps<"div"> & { index: number; }` | Cell at the required OTP input index. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `InputOTP.containerClassName` | `string` | Class for the OTP package container. |
| `InputOTPSlot.index` | `number` | Required slot index. |

## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { useState } from 'react';

import { InputOTP, InputOTPGroup, InputOTPSlot, InputOTPSeparator } from '@foglamp/design-system/ui/input-otp';

function InputOTPExample({ maxLength = 6 }: { maxLength?: number }) { const [value, setValue] = useState('482'); return <div className="grid gap-3"><p className="text-sm font-medium">Enter verification code</p><InputOTP maxLength={maxLength} value={value} onChange={setValue} aria-label="Verification code"><InputOTPGroup>{Array.from({ length: Math.min(3, maxLength) }, (_, index) => <InputOTPSlot key={index} index={index} />)}</InputOTPGroup><InputOTPSeparator /><InputOTPGroup>{Array.from({ length: Math.max(0, maxLength - 3) }, (_, index) => <InputOTPSlot key={index + 3} index={index + 3} />)}</InputOTPGroup></InputOTP><p className="text-xs text-muted-foreground">Sent to your workspace administrator.</p></div>; }
```

## Registry item

The story panel resolves this component as registry item `ui-input-otp`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-input-otp.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-input-otp.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@foglamp/design-system/ui/input-otp`. The workspace declares `@foglamp/design-system` as a package; these docs do not claim npm publication.
