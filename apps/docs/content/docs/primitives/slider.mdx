# Slider

Base UI slider with a numeric range and controlled or default values.

## Live preview

<story.WithControl />

## API and props

The table lists values exported from `@foglamp/design-system/ui/slider`. The declared type comes from the component source.

| Export | Declared props or type | Role |
| --- | --- | --- |
| `Slider` | `SliderPrimitive.Root.Props` | Slider input root. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `Slider.min` | `number` | Defaults to `0`. |
| `Slider.max` | `number` | Defaults to `100`. |
| `Slider.defaultValue` | `Base UI slider value` | Initial uncontrolled value. |
| `Slider.value` | `Base UI slider value` | Controlled value. |

## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { useState } from "react";

import { Slider } from "@foglamp/design-system/ui/slider";

import { Label } from "@foglamp/design-system/ui/label";

type Args = { value: 35 };

function SliderStory({ args }: { args: Args }) {
  const [value, setValue] = useState(35);
  return <div className="flex min-h-24 w-full items-center justify-center p-4"><div className="grid w-full max-w-sm gap-4"><div className="flex justify-between text-sm"><Label>Sampling rate</Label><span>{value}%</span></div><Slider value={[value]} min={0} max={100} step={5} onValueChange={v => setValue(typeof v === "number" ? v : (v[0] ?? 0))} aria-label="Sampling rate" /><p className="text-xs text-muted-foreground">Adjust the percentage of requests recorded.</p></div></div>;
}
```

## Registry item

The story panel resolves this component as registry item `ui-slider`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-slider.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-slider.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@foglamp/design-system/ui/slider`. The workspace declares `@foglamp/design-system` as a package; these docs do not claim npm publication.
