# Empty

Structured empty state with header, media, title, description, and content slots. Media supports default and icon variants.

## API and props

The table lists values exported from `@tailrocks/framerock/ui/empty`. The declared type comes from the component source.

| Export | Declared props or type | Role |
| --- | --- | --- |
| `Empty` | `React.ComponentProps<"div">` | Empty-state container. |
| `EmptyContent` | `React.ComponentProps<"div">` | Contains the associated popup or panel content. |
| `EmptyDescription` | `React.ComponentProps<"p">` | Descriptive text for the associated content. |
| `EmptyHeader` | `React.ComponentProps<"div">` | Header slot for title and supporting content. |
| `EmptyMedia` | `React.ComponentProps<"div"> & VariantProps<typeof emptyMediaVariants>` | Media slot for an icon or image. |
| `EmptyTitle` | `React.ComponentProps<"div">` | Title text for the associated content. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `EmptyMedia.variant` | `default \| icon` | Defaults to `default`. |

## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { Empty, EmptyHeader, EmptyMedia, EmptyTitle, EmptyDescription, EmptyContent } from '@tailrocks/framerock/ui/empty';

import { Button } from '@tailrocks/framerock/ui/button';

function EmptyExample({ title = 'No evaluations yet' }: { title?: string }) { return <Empty className="min-h-72"><EmptyHeader><EmptyMedia variant="icon"><span aria-hidden="true">▥</span></EmptyMedia><EmptyTitle>{title}</EmptyTitle><EmptyDescription>Create an evaluation to track quality across model and prompt changes.</EmptyDescription></EmptyHeader><EmptyContent><Button>Create evaluation</Button><p className="text-xs text-muted-foreground">or import a dataset from your workspace</p></EmptyContent></Empty>; }
```

## Registry item

The story panel resolves this component as registry item `ui-empty`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-empty.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-empty.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@tailrocks/framerock/ui/empty`. The workspace declares `@tailrocks/framerock` as a package; these docs do not claim npm publication.
