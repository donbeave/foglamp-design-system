# Input

Styled native input that keeps standard input attributes and forwards its input type and other native props.

## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { Input } from '@foglamp/design-system/ui/input';

import { Label } from '@foglamp/design-system/ui/label';

function InputExample({ type = 'text', placeholder = 'Project name' }: { type?: 'text' | 'email' | 'search'; placeholder?: string }) { return <div className="grid w-full max-w-sm gap-2"><Label htmlFor="input-demo">{type === 'email' ? 'Notification email' : type === 'search' ? 'Search traces' : 'Project name'}</Label><Input id="input-demo" type={type} placeholder={placeholder} defaultValue={type === 'text' ? 'Support Agent' : undefined} /></div>; }
```

## Registry item

The story panel resolves this component as registry item `ui-input`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-input.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-input.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@foglamp/design-system/ui/input`. The workspace declares `@foglamp/design-system` as a package; these docs do not claim npm publication.
