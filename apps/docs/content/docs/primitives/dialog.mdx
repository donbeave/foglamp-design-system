# Dialog

Modal dialog built from Base UI root, backdrop, popup, title, description, and close parts. The popup shows its close button by default.

## API and props

The table lists values exported from `@tailrocks/framerock/ui/dialog`. The declared type comes from the component source.

| Export | Declared props or type | Role |
| --- | --- | --- |
| `Dialog` | `DialogPrimitive.Root.Props` | Modal dialog state root. |
| `DialogClose` | `DialogPrimitive.Close.Props` | Control that closes the dialog. |
| `DialogContent` | `DialogPrimitive.Popup.Props & { showCloseButton?: boolean; }` | Dialog popup body with optional close control. |
| `DialogDescription` | `DialogPrimitive.Description.Props` | Descriptive text for the associated content. |
| `DialogFooter` | `React.ComponentProps<"div"> & { showCloseButton?: boolean; }` | Footer slot for actions or supporting content. |
| `DialogHeader` | `React.ComponentProps<"div">` | Header slot for title and supporting content. |
| `DialogOverlay` | `DialogPrimitive.Backdrop.Props` | Backdrop behind the dialog popup. |
| `DialogPortal` | `DialogPrimitive.Portal.Props` | Renders overlay content in a portal. |
| `DialogTitle` | `DialogPrimitive.Title.Props` | Title text for the associated content. |
| `DialogTrigger` | `DialogPrimitive.Trigger.Props` | Opens or toggles the associated popup or panel. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `DialogContent.showCloseButton` | `boolean` | Defaults to `true`. |
| `DialogFooter.showCloseButton` | `boolean` | Defaults to `false`. |

## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { Dialog, DialogTrigger, DialogContent, DialogHeader, DialogTitle, DialogDescription, DialogFooter, DialogClose } from '@tailrocks/framerock/ui/dialog';

import { Button } from '@tailrocks/framerock/ui/button';

import { Input } from '@tailrocks/framerock/ui/input';

import { Label } from '@tailrocks/framerock/ui/label';

function DialogExample({ title = 'Create evaluation' }: { title?: string }) { return <Dialog><DialogTrigger render={<Button variant="outline" />}>New evaluation</DialogTrigger><DialogContent><DialogHeader><DialogTitle>{title}</DialogTitle><DialogDescription>Set up a reusable test run for your agent.</DialogDescription></DialogHeader><div className="grid gap-3"><Label htmlFor="eval-name">Name</Label><Input id="eval-name" defaultValue="Support agent regression" /><Label htmlFor="eval-dataset">Dataset</Label><Input id="eval-dataset" defaultValue="support-v3 · 128 cases" /></div><DialogFooter><DialogClose render={<Button variant="outline" />}>Cancel</DialogClose><Button>Create evaluation</Button></DialogFooter></DialogContent></Dialog>; }
```

## Registry item

The story panel resolves this component as registry item `ui-dialog`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-dialog.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-dialog.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@tailrocks/framerock/ui/dialog`. The workspace declares `@tailrocks/framerock` as a package; these docs do not claim npm publication.
