# Field

Form-field composition with fieldset, legend, label, description, error, separator, and layout slots. Field orientation supports vertical, horizontal, and responsive layouts.

## API and props

The table lists values exported from `@tailrocks/framerock/ui/field`. The declared type comes from the component source.

| Export | Declared props or type | Role |
| --- | --- | --- |
| `Field` | `React.ComponentProps<"div"> & VariantProps<typeof fieldVariants>` | Field row with vertical, horizontal, or responsive layout. |
| `FieldContent` | `React.ComponentProps<"div">` | Groups the field control and its supporting content. |
| `FieldDescription` | `React.ComponentProps<"p">` | Supporting description for a field. |
| `FieldError` | `React.ComponentProps<"div"> & { errors?: Array<{ message?: string } \| undefined>; }` | Renders supplied error messages. |
| `FieldGroup` | `React.ComponentProps<"div">` | Groups related field rows. |
| `FieldLabel` | `React.ComponentProps<typeof Label>` | Label associated with a field control. |
| `FieldLegend` | `React.ComponentProps<"legend"> & { variant?: "legend" \| "label" }` | Legend for the fieldset, with legend or label treatment. |
| `FieldSeparator` | `React.ComponentProps<"div"> & { children?: React.ReactNode; }` | Visual separator between field sections. |
| `FieldSet` | `React.ComponentProps<"fieldset">` | Fieldset element for a related group of fields. |
| `FieldTitle` | `React.ComponentProps<"div">` | Title slot inside a field. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `Field.orientation` | `vertical \| horizontal \| responsive` | Defaults to `vertical`. |
| `FieldLegend.variant` | `legend \| label` | Defaults to `legend`. |
| `FieldError.errors` | `Array<{ message?: string } \| undefined>` | Error entries rendered by the field error slot. |

## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { Field, FieldLabel, FieldDescription, FieldSet, FieldLegend } from '@tailrocks/framerock/ui/field';

import { Input } from '@tailrocks/framerock/ui/input';

function FieldExample({ orientation = 'vertical' }: { orientation?: 'vertical' | 'horizontal' | 'responsive' }) { return <FieldSet className="w-full max-w-md"><FieldLegend>Project settings</FieldLegend><Field orientation={orientation}><FieldLabel htmlFor="project-name">Project name</FieldLabel><Input id="project-name" defaultValue="Customer Support Agent" /><FieldDescription>Used in dashboards and report exports.</FieldDescription></Field><Field orientation={orientation}><FieldLabel htmlFor="project-key">Project key</FieldLabel><Input id="project-key" defaultValue="support-agent" /><FieldDescription>Unique identifier for API integrations.</FieldDescription></Field></FieldSet>; }
```

## Registry item

The story panel resolves this component as registry item `ui-field`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-field.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-field.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@tailrocks/framerock/ui/field`. The workspace declares `@tailrocks/framerock` as a package; these docs do not claim npm publication.
