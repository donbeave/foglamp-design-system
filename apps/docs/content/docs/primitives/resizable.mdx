# Resizable

Panel group, panel, and resize handle composition backed by react-resizable-panels. The handle can add its visual grip.

## Live preview

<story.WithControl />

## API and props

The table lists values exported from `@foglamp/design-system/ui/resizable`. The declared type comes from the component source.

| Export | Declared props or type | Role |
| --- | --- | --- |
| `ResizableHandle` | `ResizablePrimitive.SeparatorProps & { withHandle?: boolean; }` | Panel resize handle with an optional visual grip. |
| `ResizablePanel` | `ResizablePrimitive.PanelProps` | Resizable panel region. |
| `ResizablePanelGroup` | `ResizablePrimitive.GroupProps` | Resizable panel group root. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `ResizableHandle.withHandle` | `boolean` | Render the visual grip. |

## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { useState } from "react";

import { ResizablePanelGroup, ResizablePanel, ResizableHandle } from "@foglamp/design-system/ui/resizable";

type Args = { variant: 'horizontal' };

function ResizableStory({ args }: { args: Args }) {

  return <div className="flex min-h-24 w-full items-center justify-center p-4"><ResizablePanelGroup orientation="horizontal" className="min-h-48 w-full rounded-lg shadow-(--custom-shadow)"><ResizablePanel defaultSize={36} minSize={25}><div className="h-full p-4"><p className="mb-3 text-xs font-medium uppercase text-muted-foreground">Trace list</p><div className="rounded-md bg-muted p-3 text-sm">POST /checkout</div></div></ResizablePanel><ResizableHandle withHandle /><ResizablePanel defaultSize={64}><div className="h-full p-4"><p className="mb-3 text-xs font-medium uppercase text-muted-foreground">Span details</p><p className="text-sm">payment.authorize</p><p className="mt-2 text-xs text-muted-foreground">Duration · 182 ms</p></div></ResizablePanel></ResizablePanelGroup></div>;
}
```

## Registry item

The story panel resolves this component as registry item `ui-resizable`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-resizable.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-resizable.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@foglamp/design-system/ui/resizable`. The workspace declares `@foglamp/design-system` as a package; these docs do not claim npm publication.
