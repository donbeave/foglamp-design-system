## API and props


| Export | Declared props or type | Role |
| --- | --- | --- |
| `Progress` | `ProgressPrimitive.Root.Props` | Progress root with value and state. |
| `ProgressIndicator` | `ProgressPrimitive.Indicator.Props` | Visual fill for the current progress value. |
| `ProgressLabel` | `ProgressPrimitive.Label.Props` | Accessible label for the progress control. |
| `ProgressTrack` | `ProgressPrimitive.Track.Props` | Track behind the progress indicator. |
| `ProgressValue` | `ProgressPrimitive.Value.Props` | Formatted or raw value displayed by the progress control. |

## Additional props

The exports forward the props declared by their source component types. The public type for each export appears in the table above.

## Usage

```tsx
import { useState } from "react";
import {
  Progress,
  ProgressLabel,
  ProgressValue,
} from "@tailrocks/framerock/ui/progress";

export function ProgressExample({
  value = 68,
  label = "Indexing traces",
}: {
  value?: number;
  label?: string;
} = {}) {
  const [currentValue, setCurrentValue] = useState(value);
  return (
    <div className="w-full max-w-md">
      <Progress value={currentValue}>
        <div className="flex w-full items-center justify-between">
          <ProgressLabel>
            {label}
          </ProgressLabel>
          <ProgressValue />
        </div>
      </Progress>
      <input
        aria-label="Progress value"
        type="range"
        min="0"
        max="100"
        value={currentValue}
        onChange={(e) => setCurrentValue(Number(e.target.value))}
        className="mt-4 w-full"
      />
    </div>
  );
}
```
