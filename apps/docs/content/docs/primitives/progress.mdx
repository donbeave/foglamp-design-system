# Progress

Progress root with track, indicator, label, and value slots, backed by Base UI progress state.

## Live preview

<story.WithControl />

## API and props

The table lists values exported from `@foglamp/design-system/ui/progress`. The declared type comes from the component source.

| Export | Declared props or type | Role |
| --- | --- | --- |
| `Progress` | `ProgressPrimitive.Root.Props` | Progress root with value and state. |
| `ProgressIndicator` | `ProgressPrimitive.Indicator.Props` | Visual fill for the current progress value. |
| `ProgressLabel` | `ProgressPrimitive.Label.Props` | Accessible label for the progress control. |
| `ProgressTrack` | `ProgressPrimitive.Track.Props` | Track behind the progress indicator. |
| `ProgressValue` | `ProgressPrimitive.Value.Props` | Formatted or raw value displayed by the progress control. |

## Additional props

The exports forward the props declared by their source component types. The public type for each export appears in the table above.

## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { useState } from "react";

import { Progress, ProgressTrack, ProgressIndicator, ProgressLabel, ProgressValue } from "@foglamp/design-system/ui/progress";

type Args = { value: 68 };

function ProgressStory({ args }: { args: Args }) {
  const [value, setValue] = useState(68);
  return <div className="flex min-h-24 w-full items-center justify-center p-4"><div className="w-full max-w-md"><Progress value={args.value}><div className="mb-2 flex items-center justify-between"><ProgressLabel>Indexing traces</ProgressLabel><ProgressValue /></div><ProgressTrack><ProgressIndicator /></ProgressTrack></Progress><input aria-label="Progress value" type="range" min="0" max="100" value={args.value} onChange={e => setValue(Number(e.target.value))} className="mt-4 w-full" /></div></div>;
}
```

## Registry item

The story panel resolves this component as registry item `ui-progress`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-progress.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-progress.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@foglamp/design-system/ui/progress`. The workspace declares `@foglamp/design-system` as a package; these docs do not claim npm publication.
