# Toggle

Base UI toggle with default or outline treatment and default, small, or large size.

## Live preview

<story.WithControl />

## API and props

The table lists values exported from `@foglamp/design-system/ui/toggle`. The declared type comes from the component source.

| Export | Declared props or type | Role |
| --- | --- | --- |
| `Toggle` | `TogglePrimitive.Props & VariantProps<typeof toggleVariants>` | Toggle button with variant and size options. |
| `toggleVariants` | `Class variance recipe` | Exports the toggle class recipe. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `Toggle.variant` | `default \| outline` | Defaults to `default`. |
| `Toggle.size` | `default \| sm \| lg` | Defaults to `default`. |

## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { useState } from "react";

import { Toggle } from "@foglamp/design-system/ui/toggle";

type Args = { bold: false };

function ToggleStory({ args }: { args: Args }) {
  const [bold, setBold] = useState(false);
  return <div className="flex min-h-24 w-full items-center justify-center p-4"><div className="grid gap-3"><div className="flex gap-2"><Toggle aria-label="Bold" pressed={bold} onPressedChange={setBold}><strong>B</strong></Toggle><Toggle aria-label="Italic"><em>I</em></Toggle><Toggle aria-label="Underline"><u>U</u></Toggle></div><p className="text-sm">Formatting controls for a prompt editor.</p></div></div>;
}
```

## Registry item

The story panel resolves this component as registry item `ui-toggle`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-toggle.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-toggle.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@foglamp/design-system/ui/toggle`. The workspace declares `@foglamp/design-system` as a package; these docs do not claim npm publication.
