## API and props


| Export | Declared props or type | Role |
| --- | --- | --- |
| `NavigationMenu` | `NavigationMenuPrimitive.Root.Props & Pick<NavigationMenuPrimitive.Positioner.Props, "align">` | Navigation menu root. |
| `NavigationMenuContent` | `NavigationMenuPrimitive.Content.Props` | Panel associated with a navigation menu item. |
| `NavigationMenuIndicator` | `React.ComponentPropsWithRef<typeof NavigationMenuPrimitive.Icon>` | Indicator for the active navigation item. |
| `NavigationMenuItem` | `React.ComponentPropsWithRef<typeof NavigationMenuPrimitive.Item>` | One navigation menu item. |
| `NavigationMenuLink` | `NavigationMenuPrimitive.Link.Props` | Navigation link that closes the menu on activation by default. |
| `NavigationMenuList` | `React.ComponentPropsWithRef<typeof NavigationMenuPrimitive.List>` | List container for navigation menu items. |
| `NavigationMenuPositioner` | `NavigationMenuPrimitive.Positioner.Props` | Positions the navigation popup relative to its root. |
| `NavigationMenuTrigger` | `NavigationMenuPrimitive.Trigger.Props` | Control that opens the navigation content. |
| `navigationMenuTriggerStyle` | `Navigation menu trigger class recipe` | Exports the navigation menu class recipe. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `NavigationMenu.align` | `Base UI positioner alignment` | Defaults to `start`. |
| `NavigationMenuPositioner.side` | `Base UI positioner side` | Defaults to `bottom`. |
| `NavigationMenuPositioner.sideOffset` | `number` | Defaults to `8`. |
| `NavigationMenuLink.closeOnClick` | `boolean` | Defaults to `true`. |

## Usage

```tsx
import {
  NavigationMenu,
  NavigationMenuList,
  NavigationMenuItem,
  NavigationMenuTrigger,
  NavigationMenuContent,
  NavigationMenuLink,
} from "@tailrocks/framerock/ui/navigation-menu";

export function NavigationMenuExample({
  primaryLabel = "Platform",
  secondaryLabel = "Resources",
}: {
  primaryLabel?: string;
  secondaryLabel?: string;
} = {}) {
  return (
    <NavigationMenu>
      <NavigationMenuList>
        <NavigationMenuItem>
          <NavigationMenuTrigger>
            {primaryLabel}
          </NavigationMenuTrigger>
          <NavigationMenuContent>
            <div className="grid w-[22rem] gap-2 p-3">
              <NavigationMenuLink
                href="#traces"
                className="rounded-md p-3 hover:bg-muted"
              >
                <strong className="block text-sm">Trace explorer</strong>
                <span className="text-xs text-muted-foreground">
                  Inspect model calls and latency.
                </span>
              </NavigationMenuLink>
              <NavigationMenuLink
                href="#evaluations"
                className="rounded-md p-3 hover:bg-muted"
              >
                <strong className="block text-sm">Evaluations</strong>
                <span className="text-xs text-muted-foreground">
                  Compare quality over time.
                </span>
              </NavigationMenuLink>
            </div>
          </NavigationMenuContent>
        </NavigationMenuItem>
        <NavigationMenuItem>
          <NavigationMenuTrigger>
            {secondaryLabel}
          </NavigationMenuTrigger>
          <NavigationMenuContent>
            <NavigationMenuLink href="#docs" className="block p-4">
              Documentation
            </NavigationMenuLink>
          </NavigationMenuContent>
        </NavigationMenuItem>
      </NavigationMenuList>
    </NavigationMenu>
  );
}
```
