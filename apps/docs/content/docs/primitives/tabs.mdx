## API and props

The table lists values exported from `@tailrocks/framerock/ui/tabs`. The declared type comes from the component source.

| Export | Declared props or type | Role |
| --- | --- | --- |
| `Tabs` | `TabsPrimitive.Root.Props` | Tabs state root. |
| `TabsContent` | `TabsPrimitive.Panel.Props` | Contains the associated popup or panel content. |
| `TabsList` | `TabsPrimitive.List.Props & VariantProps<typeof tabsListVariants>` | List container for related entries. |
| `tabsListVariants` | `Class variance recipe` | Exports the tabs class recipe. |
| `TabsTrigger` | `TabsPrimitive.Tab.Props` | Opens or toggles the associated popup or panel. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `Tabs.orientation` | `horizontal \| vertical` | Defaults to `horizontal`. |
| `TabsList.variant` | `default \| line` | Defaults to `default`. |

## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { useState } from "react";

import { Tabs, TabsList, TabsTrigger, TabsContent } from "@tailrocks/framerock/ui/tabs";

type Args = { variant: 'overview' };

function TabsStory({ args }: { args: Args }) {

  return <div className="flex min-h-24 w-full items-center justify-center p-4"><Tabs defaultValue="overview" className="w-full max-w-md"><TabsList><TabsTrigger value="overview">Overview</TabsTrigger><TabsTrigger value="prompt">Prompt</TabsTrigger><TabsTrigger value="response">Response</TabsTrigger></TabsList><TabsContent value="overview" className="rounded-md p-4 text-sm shadow-(--custom-shadow)">Request completed in 1.42 seconds across 12 spans.</TabsContent><TabsContent value="prompt" className="rounded-md p-4 font-mono text-xs shadow-(--custom-shadow)">Summarize the customer request…</TabsContent><TabsContent value="response" className="rounded-md p-4 text-sm shadow-(--custom-shadow)">Your order is on its way.</TabsContent></Tabs></div>;
}
```

## Registry item

The story panel resolves this component as registry item `ui-tabs`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-tabs.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-tabs.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@tailrocks/framerock/ui/tabs`. The workspace declares `@tailrocks/framerock` as a package; these docs do not claim npm publication.
