## API and props


| Export | Declared props or type | Role |
| --- | --- | --- |
| `ContextMenu` | `ContextMenuPrimitive.Root.Props` | Right-click menu root. |
| `ContextMenuCheckboxItem` | `ContextMenuPrimitive.CheckboxItem.Props & { inset?: boolean; }` | Menu item with checkbox state. |
| `ContextMenuContent` | `ContextMenuPrimitive.Popup.Props & Pick< ContextMenuPrimitive.Positioner.Props, "align" \| "alignOffset" \| "side" \| "sideOffset" >` | Positioned context menu popup. |
| `ContextMenuGroup` | `ContextMenuPrimitive.Group.Props` | Groups related entries. |
| `ContextMenuItem` | `ContextMenuPrimitive.Item.Props & { inset?: boolean; variant?: "default" \| "destructive"; }` | One selectable context command. |
| `ContextMenuLabel` | `ContextMenuPrimitive.GroupLabel.Props & { inset?: boolean; }` | Label for the associated control or group. |
| `ContextMenuPortal` | `ContextMenuPrimitive.Portal.Props` | Renders overlay content in a portal. |
| `ContextMenuRadioGroup` | `ContextMenuPrimitive.RadioGroup.Props` | Groups mutually exclusive menu items. |
| `ContextMenuRadioItem` | `ContextMenuPrimitive.RadioItem.Props & { inset?: boolean; }` | Menu item with radio state. |
| `ContextMenuSeparator` | `ContextMenuPrimitive.Separator.Props` | Visual or semantic divider. |
| `ContextMenuShortcut` | `React.ComponentProps<"span">` | Keyboard shortcut label. |
| `ContextMenuSub` | `ContextMenuPrimitive.SubmenuRoot.Props` | Declares a nested submenu. |
| `ContextMenuSubContent` | `React.ComponentProps<typeof ContextMenuContent>` | Contains nested submenu entries. |
| `ContextMenuSubTrigger` | `ContextMenuPrimitive.SubmenuTrigger.Props & { inset?: boolean; }` | Opens a nested submenu. |
| `ContextMenuTrigger` | `ContextMenuPrimitive.Trigger.Props` | Element that opens the context menu. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `ContextMenuLabel.inset` | `boolean` | Align the label with inset menu items. |
| `ContextMenuItem.inset` | `boolean` | Indent the item. |
| `ContextMenuItem.variant` | `default \| destructive` | Defaults to `default`. |
| `ContextMenuSubTrigger.inset` | `boolean` | Indent the submenu trigger. |
| `ContextMenuCheckboxItem.inset` | `boolean` | Indent the checkbox item. |
| `ContextMenuRadioItem.inset` | `boolean` | Indent the radio item. |

## Usage

```tsx
import {
  ContextMenu,
  ContextMenuTrigger,
  ContextMenuContent,
  ContextMenuItem,
  ContextMenuLabel,
  ContextMenuGroup,
  ContextMenuSeparator,
  ContextMenuShortcut,
} from "@tailrocks/framerock/ui/context-menu";

export function ContextMenuExample({
  target = 'span: checkout-api',
}: {
  target?: string;
} = {}) {
  return (
    <ContextMenu>
      <ContextMenuTrigger
        className="flex h-32 w-full max-w-md items-center justify-center rounded-lg border border-dashed bg-muted/40 text-sm text-muted-foreground"
      >
        Right-click
        {target}
      </ContextMenuTrigger>
      <ContextMenuContent>
        <ContextMenuGroup>
          <ContextMenuLabel>Trace actions</ContextMenuLabel>
          <ContextMenuItem>
            Open trace
            <ContextMenuShortcut>↵</ContextMenuShortcut>
          </ContextMenuItem>
          <ContextMenuItem>
            Copy trace ID
            <ContextMenuShortcut>⌘C</ContextMenuShortcut>
          </ContextMenuItem>
          <ContextMenuItem>View related logs</ContextMenuItem>
        </ContextMenuGroup>
        <ContextMenuSeparator />
      </ContextMenuContent>
    </ContextMenu>
  );
}
```
