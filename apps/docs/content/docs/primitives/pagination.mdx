# Pagination

Navigation landmark with page list, active link, previous and next controls, and an ellipsis marker.

## Live preview

<story.WithControl />

## API and props

The table lists values exported from `@foglamp/design-system/ui/pagination`. The declared type comes from the component source.

| Export | Declared props or type | Role |
| --- | --- | --- |
| `Pagination` | `React.ComponentProps<"nav">` | Navigation landmark for page controls. |
| `PaginationContent` | `React.ComponentProps<"ul">` | Contains the associated popup or panel content. |
| `PaginationEllipsis` | `React.ComponentProps<"span">` | Truncation marker for omitted pages or content. |
| `PaginationItem` | `React.ComponentProps<"li">` | One selectable or repeated entry. |
| `PaginationLink` | `PaginationLinkProps` | Page link with active state and Button size. |
| `PaginationNext` | `React.ComponentProps<typeof PaginationLink> & { text?: string }` | Next-item or next-page control. |
| `PaginationPrevious` | `React.ComponentProps<typeof PaginationLink> & { text?: string }` | Previous-item or previous-page control. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `PaginationLink.isActive` | `boolean` | Marks the current page. |
| `PaginationLink.size` | `Button size` | Defaults to `icon-sm`. |
| `PaginationPrevious.text` | `string` | Defaults to `Previous`. |
| `PaginationNext.text` | `string` | Defaults to `Next`. |

## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { useState } from "react";

import { Pagination, PaginationContent, PaginationItem, PaginationLink, PaginationPrevious, PaginationNext, PaginationEllipsis } from "@foglamp/design-system/ui/pagination";

type Args = { variant: 'default' };

function PaginationStory({ args }: { args: Args }) {

  return <div className="flex min-h-24 w-full items-center justify-center p-4"><Pagination><PaginationContent><PaginationItem><PaginationPrevious href="#previous" /></PaginationItem><PaginationItem><PaginationLink href="#1" isActive>1</PaginationLink></PaginationItem><PaginationItem><PaginationLink href="#2">2</PaginationLink></PaginationItem><PaginationItem><PaginationLink href="#3">3</PaginationLink></PaginationItem><PaginationItem><PaginationEllipsis /></PaginationItem><PaginationItem><PaginationNext href="#next" /></PaginationItem></PaginationContent></Pagination></div>;
}
```

## Registry item

The story panel resolves this component as registry item `ui-pagination`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-pagination.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-pagination.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@foglamp/design-system/ui/pagination`. The workspace declares `@foglamp/design-system` as a package; these docs do not claim npm publication.
