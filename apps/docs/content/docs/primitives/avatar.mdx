## API and props


| Export | Declared props or type | Role |
| --- | --- | --- |
| `Avatar` | `AvatarPrimitive.Root.Props & { size?: "default" \| "sm" \| "lg" \| "xs"; }` | Avatar root with a selected size. |
| `AvatarBadge` | `React.ComponentProps<"span">` | Positions a badge over the avatar. |
| `AvatarFallback` | `AvatarPrimitive.Fallback.Props` | Renders fallback content while the avatar image is unavailable. |
| `AvatarGroup` | `React.ComponentProps<"div">` | Groups avatars into an overlapping row. |
| `AvatarGroupCount` | `React.ComponentProps<"div">` | Displays the count of additional grouped avatars. |
| `AvatarImage` | `AvatarPrimitive.Image.Props` | Renders the avatar image and forwards Base UI image props. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `Avatar.size` | `default \| sm \| lg \| xs` | Defaults to `default`. |

## Usage

```tsx
import {
  Avatar,
  AvatarFallback,
  AvatarImage,
  AvatarBadge,
  AvatarGroup,
  AvatarGroupCount,
} from "@tailrocks/framerock/ui/avatar";

export function AvatarExample({
  size = 'default',
}: {
  size?: 'default' | 'sm' | 'lg' | 'xs';
} = {}) {
  return (
    <div className="flex flex-col gap-6">
      <Avatar size={size}>
        <AvatarImage
          src="https://images.unsplash.com/photo-1534528741775-53994a69daeb?w=96&h=96&fit=crop&crop=faces"
          alt="Portrait of Maya Chen"
        />
        <AvatarFallback>MC</AvatarFallback>
        <AvatarBadge aria-label="Online" />
      </Avatar>
      <AvatarGroup aria-label="Evaluation team">
        <Avatar>
          <AvatarFallback>MC</AvatarFallback>
        </Avatar>
        <Avatar>
          <AvatarFallback>JL</AvatarFallback>
        </Avatar>
        <Avatar>
          <AvatarFallback>AR</AvatarFallback>
        </Avatar>
        <AvatarGroupCount>+4</AvatarGroupCount>
      </AvatarGroup>
    </div>
  );
}
```
