# Native Select

Styled native select with option and option-group exports. The select supports default and compact sizes.

## API and props

The table lists values exported from `@tailrocks/framerock/ui/native-select`. The declared type comes from the component source.

| Export | Declared props or type | Role |
| --- | --- | --- |
| `NativeSelect` | `NativeSelectProps` | Styled native select element. |
| `NativeSelectOptGroup` | `React.ComponentProps<"optgroup">` | Native option group element. |
| `NativeSelectOption` | `React.ComponentProps<"option">` | Native option element. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `NativeSelect.size` | `default \| sm` | Defaults to `default`. |

## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { useState } from "react";

import { NativeSelect, NativeSelectOption } from "@tailrocks/framerock/ui/native-select";

import { Label } from "@tailrocks/framerock/ui/label";

type Args = { variant: 'default' };

function NativeSelectStory({ args }: { args: Args }) {

  return <div className="flex min-h-24 w-full items-center justify-center p-4"><div className="grid max-w-xs gap-2"><Label htmlFor="region">Deployment region</Label><NativeSelect id="region" defaultValue="us-east"><NativeSelectOption value="us-east">US East</NativeSelectOption><NativeSelectOption value="eu-west">EU West</NativeSelectOption><NativeSelectOption value="ap-south">Asia Pacific</NativeSelectOption></NativeSelect><p className="text-xs text-muted-foreground">Uses the browser’s native selection menu.</p></div></div>;
}
```

## Registry item

The story panel resolves this component as registry item `ui-native-select`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-native-select.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-native-select.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@tailrocks/framerock/ui/native-select`. The workspace declares `@tailrocks/framerock` as a package; these docs do not claim npm publication.
