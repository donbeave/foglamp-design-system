# Loader

Text shimmer indicator with a configurable message, size, and class name.

## Live preview

<story.WithControl />

## API and props

The table lists values exported from `@foglamp/design-system/ui/loader`. The declared type comes from the component source.

| Export | Declared props or type | Role |
| --- | --- | --- |
| `TextShimmerLoader` | `TextShimmerLoaderProps` | Text shimmer loading indicator with message and size props. |
| `TextShimmerLoaderProps` | `type { text?: string; size?: "sm" \| "md" \| "lg"; className?: string; }` | Public props type for TextShimmerLoader. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `TextShimmerLoader.text` | `string` | Defaults to `Thinking`. |
| `TextShimmerLoader.size` | `sm \| md \| lg` | Defaults to `md`. |
| `TextShimmerLoader.className` | `string` | Additional text-shimmer classes. |

## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { useState } from "react";

import { TextShimmerLoader } from "@foglamp/design-system/ui/loader";

type Args = { label: 'Thinking through the trace…', size: 'md' };

function LoaderStory({ args }: { args: Args }) {

  return <div className="flex min-h-24 w-full items-center justify-center p-4"><div className="grid gap-3"><TextShimmerLoader text={args.label} size={args.size} /><p className="text-xs text-muted-foreground">The shimmer announces an active model response.</p></div></div>;
}
```

## Registry item

The story panel resolves this component as registry item `ui-loader`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-loader.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-loader.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@foglamp/design-system/ui/loader`. The workspace declares `@foglamp/design-system` as a package; these docs do not claim npm publication.
