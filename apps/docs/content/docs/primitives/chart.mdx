# Chart

Chart container, tooltip, and legend helpers for Recharts. ChartConfig maps series keys to labels and optional color or icon metadata.

## API and props

The table lists values exported from `@tailrocks/framerock/ui/chart`. The declared type comes from the component source.

| Export | Declared props or type | Role |
| --- | --- | --- |
| `ChartConfig` | `type Record< string, { label?: React.ReactNode; icon?: React.ComponentType; } & ( \| { color?: string; theme?: never } \| { color?: never; theme: Record<keyof typeof THEMES, string> } ) >` | Series configuration for the chart, tooltip, and legend. |
| `ChartContainer` | `React.ComponentProps<"div"> & { config: ChartConfig; children: React.ComponentProps< typeof RechartsPrimitive.ResponsiveContainer >["children"]; initialDimension?: { width: number; height: number; }; }` | Responsive chart wrapper with series configuration. |
| `ChartLegend` | `typeof RechartsPrimitive.Legend` | Re-export of the Recharts legend primitive. |
| `ChartLegendContent` | `React.ComponentProps<"div"> & { hideIcon?: boolean; nameKey?: string; } & RechartsPrimitive.DefaultLegendContentProps` | Styled legend content that resolves series labels and icons through ChartConfig. |
| `ChartStyle` | `{ id: string; config: ChartConfig }` | Adds CSS variables derived from chart series configuration. |
| `ChartTooltip` | `typeof RechartsPrimitive.Tooltip` | Re-export of the Recharts tooltip primitive. |
| `ChartTooltipContent` | `React.ComponentProps<typeof RechartsPrimitive.Tooltip> & React.ComponentProps<"div"> & { hideLabel?: boolean; hideIndicator?: boolean; indicator?: "line" \| "dot" \| "dashed"; nameKey?: string; labelKey?: string; } & Omit< RechartsPrimitive.DefaultTooltipContentProps< TooltipValueType, TooltipNameType >, "accessibilityLayer" >` | Styled tooltip content that resolves labels and colors through ChartConfig. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `ChartContainer.config` | `ChartConfig` | Required series configuration. |
| `ChartContainer.initialDimension` | `{ width: number; height: number }` | Defaults to 320 by 200. |
| `ChartTooltipContent.indicator` | `line \| dot \| dashed` | Defaults to `dot`. |
| `ChartTooltipContent.hideLabel` | `boolean` | Defaults to `false`. |
| `ChartTooltipContent.hideIndicator` | `boolean` | Defaults to `false`. |
| `ChartTooltipContent.nameKey` | `string` | Config key for the tooltip series name. |
| `ChartTooltipContent.labelKey` | `string` | Config key for the tooltip label. |
| `ChartLegendContent.hideIcon` | `boolean` | Defaults to `false`. |
| `ChartLegendContent.nameKey` | `string` | Config key for the legend series name. |

## Registry item

The story panel resolves this component as registry item `ui-chart`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-chart.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-chart.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@tailrocks/framerock/ui/chart`. The workspace declares `@tailrocks/framerock` as a package; these docs do not claim npm publication.
