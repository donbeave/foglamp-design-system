## Registry item

The story panel resolves this component as registry item `ui-separator`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-separator.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-separator.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@foglamp/design-system/ui/separator`. The workspace declares `@foglamp/design-system` as a package; these docs do not claim npm publication.
