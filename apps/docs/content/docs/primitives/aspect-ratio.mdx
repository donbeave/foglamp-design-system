# Aspect Ratio

Container that keeps its content at a numeric width-to-height ratio. The ratio is required and passed to the underlying div wrapper.

## API and props

| Export | Declared props or type | Role |
| --- | --- | --- |

## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { AspectRatio } from '@tailrocks/framerock/ui/aspect-ratio';

function AspectRatioExample({ ratio = 16 / 9 }: { ratio?: number }) { return <div className="w-full max-w-xl"><AspectRatio ratio={ratio} className="overflow-hidden rounded-lg bg-muted"><div className="flex size-full flex-col items-center justify-center gap-2 bg-gradient-to-br from-primary/15 via-muted to-primary/5"><span className="text-2xl font-semibold">Trace overview</span><span className="text-sm text-muted-foreground">{ratio.toFixed(2)} : 1 preview</span></div></AspectRatio></div>; }
```

## Registry item

The story panel resolves this component as registry item `ui-aspect-ratio`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-aspect-ratio.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-aspect-ratio.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@tailrocks/framerock/ui/aspect-ratio`. The workspace declares `@tailrocks/framerock` as a package; these docs do not claim npm publication.
