# Accordion

Disclosure group for showing related trace, run, or evaluation details. The root supports multiple expanded items, as used by the shipped story.

## Live preview

<story.WithControl />

## API and props

The table lists values exported from `@foglamp/design-system/ui/accordion`. The declared type comes from the component source.

| Export | Declared props or type | Role |
| --- | --- | --- |
| `Accordion` | `AccordionPrimitive.Root.Props` | Disclosure root that coordinates expanded items. |
| `AccordionContent` | `AccordionPrimitive.Panel.Props` | Contains the associated popup or panel content. |
| `AccordionItem` | `AccordionPrimitive.Item.Props` | One selectable or repeated entry. |
| `AccordionTrigger` | `AccordionPrimitive.Trigger.Props` | Opens or toggles the associated popup or panel. |

## Additional props

The exports forward the props declared by their source component types. The public type for each export appears in the table above.

## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { Accordion, AccordionItem, AccordionTrigger, AccordionContent } from '@foglamp/design-system/ui/accordion';

function AccordionExample() { return <Accordion multiple defaultValue={['latency']}><AccordionItem value="latency"><AccordionTrigger>Latency regression</AccordionTrigger><AccordionContent><p>p95 increased from 420 ms to 680 ms after deployment.</p></AccordionContent></AccordionItem><AccordionItem value="tokens"><AccordionTrigger>Token usage</AccordionTrigger><AccordionContent><p>Input: 12.4k tokens · Output: 1.8k tokens</p></AccordionContent></AccordionItem><AccordionItem value="trace"><AccordionTrigger>Trace details</AccordionTrigger><AccordionContent><p>Three spans exceeded the service objective.</p></AccordionContent></AccordionItem></Accordion>; }
```

## Registry item

The story panel resolves this component as registry item `ui-accordion`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-accordion.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-accordion.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@foglamp/design-system/ui/accordion`. The workspace declares `@foglamp/design-system` as a package; these docs do not claim npm publication.
