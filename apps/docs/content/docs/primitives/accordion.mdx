## API and props


| Export | Declared props or type | Role |
| --- | --- | --- |
| `Accordion` | `AccordionPrimitive.Root.Props` | Disclosure root that coordinates expanded items. |
| `AccordionContent` | `AccordionPrimitive.Panel.Props` | Contains the associated popup or panel content. |
| `AccordionItem` | `AccordionPrimitive.Item.Props` | One selectable or repeated entry. |
| `AccordionTrigger` | `AccordionPrimitive.Trigger.Props` | Opens or toggles the associated popup or panel. |

## Additional props

The exports forward the props declared by their source component types. The public type for each export appears in the table above.

## Usage

```tsx
import {
  Accordion,
  AccordionItem,
  AccordionTrigger,
  AccordionContent,
} from "@tailrocks/framerock/ui/accordion";

export function AccordionExample() {
  return (
    <Accordion multiple defaultValue={['latency']}>
      <AccordionItem value="latency">
        <AccordionTrigger>Latency regression</AccordionTrigger>
        <AccordionContent>
          <p>p95 increased from 420 ms to 680 ms after deployment.</p>
        </AccordionContent>
      </AccordionItem>
      <AccordionItem value="tokens">
        <AccordionTrigger>Token usage</AccordionTrigger>
        <AccordionContent>
          <p>Input: 12.4k tokens · Output: 1.8k tokens</p>
        </AccordionContent>
      </AccordionItem>
      <AccordionItem value="trace">
        <AccordionTrigger>Trace details</AccordionTrigger>
        <AccordionContent>
          <p>Three spans exceeded the service objective.</p>
        </AccordionContent>
      </AccordionItem>
    </Accordion>
  );
}
```
