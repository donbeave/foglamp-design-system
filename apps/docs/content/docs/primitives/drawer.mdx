# Drawer

Modal drawer composition with trigger, portal, backdrop, content, heading, and footer parts, backed by the project drawer primitive.

## API and props

The table lists values exported from `@foglamp/design-system/ui/drawer`. The declared type comes from the component source.

| Export | Declared props or type | Role |
| --- | --- | --- |
| `Drawer` | `React.ComponentProps<typeof DrawerPrimitive.Root>` | Drawer root with modal state. |
| `DrawerClose` | `React.ComponentProps<typeof DrawerPrimitive.Close>` | Control that closes the drawer. |
| `DrawerContent` | `React.ComponentProps<typeof DrawerPrimitive.Content>` | Drawer panel content. |
| `DrawerDescription` | `React.ComponentProps<typeof DrawerPrimitive.Description>` | Descriptive text for the associated content. |
| `DrawerFooter` | `React.ComponentProps<"div">` | Footer slot for actions or supporting content. |
| `DrawerHeader` | `React.ComponentProps<"div">` | Header slot for title and supporting content. |
| `DrawerOverlay` | `React.ComponentProps<typeof DrawerPrimitive.Overlay>` | Backdrop behind the drawer. |
| `DrawerPortal` | `React.ComponentProps<typeof DrawerPrimitive.Portal>` | Renders overlay content in a portal. |
| `DrawerTitle` | `React.ComponentProps<typeof DrawerPrimitive.Title>` | Title text for the associated content. |
| `DrawerTrigger` | `React.ComponentProps<typeof DrawerPrimitive.Trigger>` | Opens or toggles the associated popup or panel. |

## Additional props

The exports forward the props declared by their source component types. The public type for each export appears in the table above.

## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { Drawer, DrawerTrigger, DrawerContent, DrawerHeader, DrawerTitle, DrawerDescription, DrawerFooter, DrawerClose } from '@foglamp/design-system/ui/drawer';

import { Button } from '@foglamp/design-system/ui/button';

function DrawerExample({ title = 'Trace details' }: { title?: string }) { return <Drawer><DrawerTrigger>Inspect trace</DrawerTrigger><DrawerContent><DrawerHeader><DrawerTitle>{title}</DrawerTitle><DrawerDescription>checkout-api · trace tr_7f92c1 · 2.14 s</DrawerDescription></DrawerHeader><div className="grid gap-3 px-4 py-2 text-sm"><div className="flex justify-between"><span className="text-muted-foreground">Model</span><span>Claude 3.7 Sonnet</span></div><div className="flex justify-between"><span className="text-muted-foreground">Input tokens</span><span>12,418</span></div><div className="flex justify-between"><span className="text-muted-foreground">Cost</span><span>$0.084</span></div></div><DrawerFooter><Button>Open full trace</Button><DrawerClose>Close</DrawerClose></DrawerFooter></DrawerContent></Drawer>; }
```

## Registry item

The story panel resolves this component as registry item `ui-drawer`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-drawer.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-drawer.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@foglamp/design-system/ui/drawer`. The workspace declares `@foglamp/design-system` as a package; these docs do not claim npm publication.
