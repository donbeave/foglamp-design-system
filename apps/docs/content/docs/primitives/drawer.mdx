## API and props


| Export | Declared props or type | Role |
| --- | --- | --- |
| `Drawer` | `React.ComponentProps<typeof DrawerPrimitive.Root>` | Drawer root with modal state. |
| `DrawerClose` | `React.ComponentProps<typeof DrawerPrimitive.Close>` | Control that closes the drawer. |
| `DrawerContent` | `React.ComponentProps<typeof DrawerPrimitive.Content>` | Drawer panel content. |
| `DrawerDescription` | `React.ComponentProps<typeof DrawerPrimitive.Description>` | Descriptive text for the associated content. |
| `DrawerFooter` | `React.ComponentProps<"div">` | Footer slot for actions or supporting content. |
| `DrawerHeader` | `React.ComponentProps<"div">` | Header slot for title and supporting content. |
| `DrawerOverlay` | `React.ComponentProps<typeof DrawerPrimitive.Overlay>` | Backdrop behind the drawer. |
| `DrawerPortal` | `React.ComponentProps<typeof DrawerPrimitive.Portal>` | Renders overlay content in a portal. |
| `DrawerTitle` | `React.ComponentProps<typeof DrawerPrimitive.Title>` | Title text for the associated content. |
| `DrawerTrigger` | `React.ComponentProps<typeof DrawerPrimitive.Trigger>` | Opens or toggles the associated popup or panel. |

## Additional props

The exports forward the props declared by their source component types. The public type for each export appears in the table above.

## Usage

```tsx
import {
  Drawer,
  DrawerTrigger,
  DrawerContent,
  DrawerHeader,
  DrawerTitle,
  DrawerDescription,
  DrawerFooter,
  DrawerClose,
} from "@tailrocks/framerock/ui/drawer";
import { Button } from "@tailrocks/framerock/ui/button";

export function DrawerExample({
  title = 'Trace details',
}: {
  title?: string;
} = {}) {
  return (
    <Drawer>
      <DrawerTrigger>Inspect trace</DrawerTrigger>
      <DrawerContent>
        <DrawerHeader>
          <DrawerTitle>
            {title}
          </DrawerTitle>
          <DrawerDescription>
            checkout-api · trace tr_7f92c1 · 2.14 s
          </DrawerDescription>
        </DrawerHeader>
        <div className="grid gap-3 px-4 py-2 text-sm">
          <div className="flex justify-between">
            <span className="text-muted-foreground">Model</span>
            <span>Claude 3.7 Sonnet</span>
          </div>
          <div className="flex justify-between">
            <span className="text-muted-foreground">Input tokens</span>
            <span>12,418</span>
          </div>
          <div className="flex justify-between">
            <span className="text-muted-foreground">Cost</span>
            <span>$0.084</span>
          </div>
        </div>
        <DrawerFooter>
          <Button>Open full trace</Button>
          <DrawerClose>Close</DrawerClose>
        </DrawerFooter>
      </DrawerContent>
    </Drawer>
  );
}
```
