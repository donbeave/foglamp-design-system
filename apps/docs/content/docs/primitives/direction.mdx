# Direction

Direction provider and hook used to set or read left-to-right and right-to-left layout context.

## Live preview

<story.WithControl />

## API and props

The table lists values exported from `@foglamp/design-system/ui/direction`. The declared type comes from the component source.

| Export | Declared props or type | Role |
| --- | --- | --- |
| `DirectionProvider` | `React.FC<DirectionProvider.Props>` | Provides direction context to Base UI components. |
| `useDirection` | `() => TextDirection` | Reads the direction context. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `DirectionProvider.direction` | `TextDirection` | Direction provided to descendant components. Defaults to `ltr`. |

## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { DirectionProvider, useDirection } from '@foglamp/design-system/ui/direction';

import { Button } from '@foglamp/design-system/ui/button';

function DirectionContent() { const direction = useDirection(); return <div dir={direction} className="grid gap-3"><p className="text-sm">Current direction: <strong>{direction}</strong></p><div className="flex gap-2"><Button variant="outline">Previous</Button><Button>Continue</Button></div></div>; }

function DirectionExample({ direction = 'ltr' }: { direction?: 'ltr' | 'rtl' }) { return <DirectionProvider direction={direction}><DirectionContent /></DirectionProvider>; }
```

## Registry item

The story panel resolves this component as registry item `ui-direction`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-direction.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-direction.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@foglamp/design-system/ui/direction`. The workspace declares `@foglamp/design-system` as a package; these docs do not claim npm publication.
