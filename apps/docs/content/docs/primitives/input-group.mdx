# Input Group

Input or textarea composition with aligned addons, buttons, and text. Addon alignment and button size and variant are configurable.

<story.WithControl />

## API and props

The table lists values exported from `@foglamp/design-system/ui/input-group`. The declared type comes from the component source.

| Export | Declared props or type | Role |
| --- | --- | --- |
| `InputGroup` | `React.ComponentProps<"div">` | Container that aligns an input with addons and actions. |
| `InputGroupAddon` | `React.ComponentProps<"div"> & VariantProps<typeof inputGroupAddonVariants>` | Addon positioned at the selected inline or block edge. |
| `InputGroupButton` | `Omit<React.ComponentProps<typeof Button>, "size" \| "type"> & VariantProps<typeof inputGroupButtonVariants> & { type?: "button" \| "submit" \| "reset"; }` | Button styled for the compact input group. |
| `InputGroupInput` | `React.ComponentProps<"input">` | Input styled to align with input group addons. |
| `InputGroupText` | `React.ComponentProps<"span">` | Text addon for an input group. |
| `InputGroupTextarea` | `React.ComponentProps<"textarea">` | Textarea styled to align with input group addons. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `InputGroupAddon.align` | `inline-start \| inline-end \| block-start \| block-end` | Defaults to `inline-start`. |
| `InputGroupButton.variant` | `Button variant` | Defaults to `ghost`. |
| `InputGroupButton.size` | `xs \| sm \| icon-xs \| icon-sm` | Defaults to `xs`. |
| `InputGroupButton.type` | `button \| submit \| reset` | Defaults to `button`. |

## Registry item

The story panel resolves this component as registry item `ui-input-group`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-input-group.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-input-group.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@foglamp/design-system/ui/input-group`. The workspace declares `@foglamp/design-system` as a package; these docs do not claim npm publication.
