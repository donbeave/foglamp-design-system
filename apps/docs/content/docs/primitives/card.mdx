# Card

Content container composed from header, title, description, action, body, and footer slots. The root offers default and compact sizes.

## Live preview

<story.WithControl />

## API and props

The table lists values exported from `@foglamp/design-system/ui/card`. The declared type comes from the component source.

| Export | Declared props or type | Role |
| --- | --- | --- |
| `Card` | `React.ComponentProps<"div"> & { size?: "default" \| "sm" }` | Card container with default or compact density. |
| `CardAction` | `React.ComponentProps<"div">` | Action slot or action control. |
| `CardContent` | `React.ComponentProps<"div">` | Contains the associated popup or panel content. |
| `CardDescription` | `React.ComponentProps<"div">` | Descriptive text for the associated content. |
| `CardFooter` | `React.ComponentProps<"div">` | Footer slot for actions or supporting content. |
| `CardHeader` | `React.ComponentProps<"div">` | Header slot for title and supporting content. |
| `CardTitle` | `React.ComponentProps<"div">` | Title text for the associated content. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `Card.size` | `default \| sm` | Defaults to `default`. |

## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { Card, CardHeader, CardTitle, CardDescription, CardAction, CardContent, CardFooter } from '@foglamp/design-system/ui/card';

import { Button } from '@foglamp/design-system/ui/button';

import { Badge } from '@foglamp/design-system/ui/badge';

function CardExample({ size = 'default' }: { size?: 'default' | 'sm' }) { return <Card size={size} className="w-full max-w-md"><CardHeader><CardTitle>Production evaluation</CardTitle><CardDescription>Customer support agent · updated 4 min ago</CardDescription><CardAction><Badge variant="green">Passed</Badge></CardAction></CardHeader><CardContent><div className="flex items-baseline gap-2"><span className="text-3xl font-semibold">94.8</span><span className="text-muted-foreground">/ 100</span></div><p className="mt-1 text-sm text-muted-foreground">Across 128 test cases</p></CardContent><CardFooter className="justify-between border-t"><span className="text-xs text-muted-foreground">v2.8.1 · 2m 14s</span><Button size="sm" variant="outline">Open report</Button></CardFooter></Card>; }
```

## Registry item

The story panel resolves this component as registry item `ui-card`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-card.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-card.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@foglamp/design-system/ui/card`. The workspace declares `@foglamp/design-system` as a package; these docs do not claim npm publication.
