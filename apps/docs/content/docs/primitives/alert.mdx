## API and props


| Export | Declared props or type | Role |
| --- | --- | --- |
| `Alert` | `React.ComponentProps<"div"> & VariantProps<typeof alertVariants>` | Status container with a selected treatment. |
| `AlertAction` | `React.ComponentProps<"div">` | Action slot or action control. |
| `AlertDescription` | `React.ComponentProps<"div">` | Descriptive text for the associated content. |
| `AlertTitle` | `React.ComponentProps<"div">` | Title text for the associated content. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `Alert.variant` | `default \| destructive` | Alert treatment. |

## Usage

```tsx
import {
  Alert,
  AlertTitle,
  AlertDescription,
} from "@tailrocks/framerock/ui/alert";
import { Badge } from "@tailrocks/framerock/ui/badge";

export function AlertExample({
  variant = 'default',
}: {
  variant?: 'default' | 'destructive';
} = {}) {
  return (
    <Alert variant={variant}>
      <AlertTitle>
        {variant === 'destructive' ? 'Run failed' : 'Deployment complete'}
      </AlertTitle>
      <AlertDescription>
        {variant === 'destructive' ? 'The evaluator returned a non-zero status.' : 'Production is serving release v2.8.1.'}
      </AlertDescription>
    </Alert>
  );
}
```
