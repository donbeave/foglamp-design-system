# Alert

Compact status or warning container with separate title, description, and action slots. The wrapper offers default and destructive treatments.

## Live preview

<story.WithControl />

## API and props

The table lists values exported from `@foglamp/design-system/ui/alert`. The declared type comes from the component source.

| Export | Declared props or type | Role |
| --- | --- | --- |
| `Alert` | `React.ComponentProps<"div"> & VariantProps<typeof alertVariants>` | Status container with a selected treatment. |
| `AlertAction` | `React.ComponentProps<"div">` | Action slot or action control. |
| `AlertDescription` | `React.ComponentProps<"div">` | Descriptive text for the associated content. |
| `AlertTitle` | `React.ComponentProps<"div">` | Title text for the associated content. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `Alert.variant` | `default \| destructive` | Alert treatment. |

## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { Alert, AlertTitle, AlertDescription } from '@foglamp/design-system/ui/alert';

import { Badge } from '@foglamp/design-system/ui/badge';

function AlertExample({ variant = 'default' }: { variant?: 'default' | 'destructive' }) { return <Alert variant={variant}><AlertTitle>{variant === 'destructive' ? 'Run failed' : 'Deployment complete'}</AlertTitle><AlertDescription>{variant === 'destructive' ? 'The evaluator returned a non-zero status.' : 'Production is serving release v2.8.1.'}</AlertDescription></Alert>; }
```

## Registry item

The story panel resolves this component as registry item `ui-alert`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-alert.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-alert.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@foglamp/design-system/ui/alert`. The workspace declares `@foglamp/design-system` as a package; these docs do not claim npm publication.
