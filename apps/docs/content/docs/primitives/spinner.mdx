## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { useState } from "react";

import { Spinner } from "@foglamp/design-system/ui/spinner";

type Args = { variant: 'default' };

function SpinnerStory({ args }: { args: Args }) {

  return <div className="flex min-h-24 w-full items-center justify-center p-4"><div className="flex items-center gap-3"><Spinner /><span className="text-sm">Loading trace details</span></div></div>;
}
```

## Registry item

The story panel resolves this component as registry item `ui-spinner`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-spinner.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-spinner.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@foglamp/design-system/ui/spinner`. The workspace declares `@foglamp/design-system` as a package; these docs do not claim npm publication.
