# Kbd

Keyboard-key label and group wrapper for displaying one key or a sequence of keys.

<story.WithControl />

## API and props

The table lists values exported from `@foglamp/design-system/ui/kbd`. The declared type comes from the component source.

| Export | Declared props or type | Role |
| --- | --- | --- |
| `Kbd` | `React.ComponentProps<"kbd">` | Keyboard-key label. |

The exports forward the props declared by their source component types. The public type for each export appears in the table above.

## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { useState } from "react";

import { Kbd, KbdGroup } from "@foglamp/design-system/ui/kbd";

type Args = { variant: 'default' };

function KbdStory({ args }: { args: Args }) {

  return <div className="flex min-h-24 w-full items-center justify-center p-4"><div className="flex flex-col gap-4"><p className="text-sm">Open command search</p><KbdGroup><Kbd>⌘</Kbd><Kbd>K</Kbd></KbdGroup><p className="text-sm text-muted-foreground">Keyboard shortcuts stay legible in both themes.</p></div></div>;
}
```

## Registry item

The story panel resolves this component as registry item `ui-kbd`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-kbd.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-kbd.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@foglamp/design-system/ui/kbd`. The workspace declares `@foglamp/design-system` as a package; these docs do not claim npm publication.
