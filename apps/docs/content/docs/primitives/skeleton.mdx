## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { useState } from "react";

import { Skeleton } from "@tailrocks/framerock/ui/skeleton";

type Args = { variant: 'card' };

function SkeletonStory({ args }: { args: Args }) {

  return <div className="flex min-h-24 w-full items-center justify-center p-4"><div className="w-full max-w-sm space-y-3"><div className="flex items-center gap-3"><Skeleton className="size-10 rounded-full" /><div className="flex-1 space-y-2"><Skeleton className="h-3 w-1/2" /><Skeleton className="h-3 w-3/4" /></div></div><Skeleton className="h-24 w-full rounded-lg" /><p className="text-xs text-muted-foreground">A trace card loading placeholder.</p></div></div>;
}
```

## Registry item

The story panel resolves this component as registry item `ui-skeleton`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-skeleton.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-skeleton.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@tailrocks/framerock/ui/skeleton`. The workspace declares `@tailrocks/framerock` as a package; these docs do not claim npm publication.
