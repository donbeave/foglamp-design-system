# Menubar

Horizontal Base UI menubar composed with menu, trigger, popup, item, submenu, radio, checkbox, separator, and shortcut parts.

## API and props

The table lists values exported from `@foglamp/design-system/ui/menubar`. The declared type comes from the component source.

| Export | Declared props or type | Role |
| --- | --- | --- |
| `Menubar` | `MenubarPrimitive.Props` | Horizontal menubar root. |
| `MenubarCheckboxItem` | `MenuPrimitive.CheckboxItem.Props & { inset?: boolean; }` | Menu item with checkbox state. |
| `MenubarContent` | `React.ComponentProps<typeof DropdownMenuContent>` | Positioned menubar popup. |
| `MenubarGroup` | `React.ComponentProps<typeof DropdownMenuGroup>` | Groups related entries. |
| `MenubarItem` | `React.ComponentProps<typeof DropdownMenuItem>` | One menubar command. |
| `MenubarLabel` | `React.ComponentProps<typeof DropdownMenuLabel> & { inset?: boolean; }` | Label for the associated control or group. |
| `MenubarMenu` | `React.ComponentProps<typeof DropdownMenu>` | Root for one menubar and its menu items. |
| `MenubarPortal` | `React.ComponentProps<typeof DropdownMenuPortal>` | Renders overlay content in a portal. |
| `MenubarRadioGroup` | `React.ComponentProps<typeof DropdownMenuRadioGroup>` | Groups mutually exclusive menu items. |
| `MenubarRadioItem` | `MenuPrimitive.RadioItem.Props & { inset?: boolean; }` | Menu item with radio state. |
| `MenubarSeparator` | `React.ComponentProps<typeof DropdownMenuSeparator>` | Visual or semantic divider. |
| `MenubarShortcut` | `React.ComponentProps<typeof DropdownMenuShortcut>` | Keyboard shortcut label. |
| `MenubarSub` | `React.ComponentProps<typeof DropdownMenuSub>` | Declares a nested submenu. |
| `MenubarSubContent` | `React.ComponentProps<typeof DropdownMenuSubContent>` | Popup containing nested menubar entries. |
| `MenubarSubTrigger` | `React.ComponentProps<typeof DropdownMenuSubTrigger> & { inset?: boolean; }` | Control that opens a nested menubar submenu. |
| `MenubarTrigger` | `React.ComponentProps<typeof DropdownMenuTrigger>` | Control that opens a menubar menu. |

## Additional props

The exports forward the props declared by their source component types. The public type for each export appears in the table above.

## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { useState } from "react";

import { Menubar, MenubarMenu, MenubarTrigger, MenubarContent, MenubarItem, MenubarSeparator, MenubarShortcut } from "@foglamp/design-system/ui/menubar";

type Args = { variant: 'default' };

function MenubarStory({ args }: { args: Args }) {

  return <div className="flex min-h-24 w-full items-center justify-center p-4"><Menubar><MenubarMenu><MenubarTrigger>File</MenubarTrigger><MenubarContent><MenubarItem>New workspace <MenubarShortcut>⌘N</MenubarShortcut></MenubarItem><MenubarItem>Open trace <MenubarShortcut>⌘O</MenubarShortcut></MenubarItem><MenubarSeparator /><MenubarItem>Export report</MenubarItem></MenubarContent></MenubarMenu><MenubarMenu><MenubarTrigger>View</MenubarTrigger><MenubarContent><MenubarItem>Show activity</MenubarItem></MenubarContent></MenubarMenu></Menubar></div>;
}
```

## Registry item

The story panel resolves this component as registry item `ui-menubar`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-menubar.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-menubar.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@foglamp/design-system/ui/menubar`. The workspace declares `@foglamp/design-system` as a package; these docs do not claim npm publication.
