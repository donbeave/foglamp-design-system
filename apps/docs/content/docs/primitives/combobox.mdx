## API and props


| Export | Declared props or type | Role |
| --- | --- | --- |
| `Combobox` | `typeof ComboboxPrimitive.Root` | Searchable selection root; the child controls use the wrapper exports. |
| `ComboboxChip` | `ComboboxPrimitive.Chip.Props & { showRemove?: boolean; }` | Selected value chip with an optional remove control. |
| `ComboboxChips` | `React.ComponentPropsWithRef<typeof ComboboxPrimitive.Chips> & ComboboxPrimitive.Chips.Props` | Container for the selected chips and chips input. |
| `ComboboxChipsInput` | `ComboboxPrimitive.Input.Props` | Input control for the composition. |
| `ComboboxCollection` | `ComboboxPrimitive.Collection.Props` | Renders the active option collection. |
| `ComboboxContent` | `ComboboxPrimitive.Popup.Props & Pick< ComboboxPrimitive.Positioner.Props, "side" \| "align" \| "sideOffset" \| "alignOffset" \| "anchor" >` | Contains the associated popup or panel content. |
| `ComboboxEmpty` | `ComboboxPrimitive.Empty.Props` | Content displayed when the combobox has no matching options. |
| `ComboboxGroup` | `ComboboxPrimitive.Group.Props` | Groups related combobox options. |
| `ComboboxInput` | `ComboboxPrimitive.Input.Props & { showTrigger?: boolean; showClear?: boolean; }` | Input control for the composition. |
| `ComboboxItem` | `ComboboxPrimitive.Item.Props` | One selectable combobox option. |
| `ComboboxLabel` | `ComboboxPrimitive.GroupLabel.Props` | Label for a combobox option group. |
| `ComboboxList` | `ComboboxPrimitive.List.Props` | List of combobox options. |
| `ComboboxSeparator` | `ComboboxPrimitive.Separator.Props` | Visual divider between combobox options. |
| `ComboboxTrigger` | `ComboboxPrimitive.Trigger.Props` | Opens or toggles the associated popup or panel. |
| `ComboboxValue` | `ComboboxPrimitive.Value.Props` | Displays the selected combobox value. |
| `useComboboxAnchor` | `Exported component or value` | Returns the combobox anchor ref and positioning props. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `ComboboxInput.showTrigger` | `boolean` | Render the trigger affordance. Defaults to `true`. |
| `ComboboxInput.showClear` | `boolean` | Render the clear button. Defaults to `false`. |
| `ComboboxContent.side` | `Base UI positioner side` | Defaults to `bottom`. |
| `ComboboxContent.sideOffset` | `number` | Defaults to `6`. |
| `ComboboxContent.align` | `Base UI positioner alignment` | Defaults to `start`. |
| `ComboboxChip.showRemove` | `boolean` | Defaults to `true`. |

## Usage

```tsx
import { useState } from "react";
import {
  Combobox,
  ComboboxInput,
  ComboboxContent,
  ComboboxList,
  ComboboxItem,
  ComboboxEmpty,
} from "@tailrocks/framerock/ui/combobox";

const models = ['Claude 3.7 Sonnet', 'GPT-4.1', 'Gemini 2.5 Pro'];

export function ComboboxExample({
  placeholder = 'Choose a model…',
}: {
  placeholder?: string;
} = {}) {
  const [value, setValue] = useState<string | null>('GPT-4.1');
  return (
    <Combobox items={models} value={value} onValueChange={setValue}>
      <ComboboxInput aria-label="Model" placeholder={placeholder} />
      <ComboboxContent>
        <ComboboxList>
          {models.map((model) => (
              <ComboboxItem key={model} value={model}>
                {model}
              </ComboboxItem>
          ))}
        </ComboboxList>
        <ComboboxEmpty>No models found.</ComboboxEmpty>
      </ComboboxContent>
    </Combobox>
  );
}
```
