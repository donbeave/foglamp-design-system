## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { useState } from "react";

import { RadioGroup, RadioGroupItem } from "@tailrocks/framerock/ui/radio-group";

type Args = { variant: 'default' };

function RadioGroupStory({ args }: { args: Args }) {

  return <div className="flex min-h-24 w-full items-center justify-center p-4"><fieldset className="grid gap-3"><legend className="mb-2 text-sm font-medium">Default time range</legend>{[["1h","Last hour"],["24h","Last 24 hours"],["7d","Last 7 days"]].map(([value,label]) => <label key={value} className="flex items-center gap-3"><RadioGroupItem value={value} /><span className="text-sm">{label}</span></label>)}</fieldset></div>;
}
```

## Registry item

The story panel resolves this component as registry item `ui-radio-group`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-radio-group.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-radio-group.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@tailrocks/framerock/ui/radio-group`. The workspace declares `@tailrocks/framerock` as a package; these docs do not claim npm publication.
