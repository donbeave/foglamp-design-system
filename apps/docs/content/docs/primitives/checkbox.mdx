## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { useState } from 'react';

import { Checkbox } from '@foglamp/design-system/ui/checkbox';

import { Field, FieldLabel, FieldDescription } from '@foglamp/design-system/ui/field';

function CheckboxExample({ disabled = false }: { disabled?: boolean }) { const [checked, setChecked] = useState(true); return <Field orientation="horizontal" data-disabled={disabled}><Checkbox id="include-retries" checked={checked} onCheckedChange={setChecked} disabled={disabled} /><div><FieldLabel htmlFor="include-retries">Include retry attempts</FieldLabel><FieldDescription>Count retries as separate evaluation requests.</FieldDescription></div></Field>; }
```

## Registry item

The story panel resolves this component as registry item `ui-checkbox`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-checkbox.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-checkbox.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@foglamp/design-system/ui/checkbox`. The workspace declares `@foglamp/design-system` as a package; these docs do not claim npm publication.
