## API and props


| Export | Declared props or type | Role |
| --- | --- | --- |
| `Sheet` | `SheetPrimitive.Root.Props` | Dialog-based side panel root. |
| `SheetClose` | `SheetPrimitive.Close.Props` | Control that closes the sheet. |
| `SheetContent` | `SheetPrimitive.Popup.Props & { side?: "top" \| "right" \| "bottom" \| "left"; variant?: "default" \| "floating"; showCloseButton?: boolean; }` | Side panel popup with selected edge and treatment. |
| `SheetDescription` | `SheetPrimitive.Description.Props` | Descriptive text for the associated content. |
| `SheetFooter` | `React.ComponentProps<"div">` | Footer slot for actions or supporting content. |
| `SheetHeader` | `React.ComponentProps<"div">` | Header slot for title and supporting content. |
| `SheetTitle` | `SheetPrimitive.Title.Props` | Title text for the associated content. |
| `SheetTrigger` | `SheetPrimitive.Trigger.Props` | Opens or toggles the associated popup or panel. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `SheetContent.side` | `top \| right \| bottom \| left` | Defaults to `right`. |
| `SheetContent.variant` | `default \| floating` | Defaults to `default`. |
| `SheetContent.showCloseButton` | `boolean` | Defaults to `true`. |

## Usage

```tsx
import {
  Sheet,
  SheetTrigger,
  SheetContent,
  SheetHeader,
  SheetTitle,
  SheetDescription,
  SheetFooter,
  SheetClose,
} from "@tailrocks/framerock/ui/sheet";

export function SheetExample({
  side = "right",
  title = "Span details",
}: {
  side?: "right" | "left" | "top" | "bottom";
  title?: string;
} = {}) {
  return (
    <Sheet>
      <SheetTrigger
        className="rounded-md bg-primary px-3 py-2 text-primary-foreground"
      >
        Inspect trace
      </SheetTrigger>
      <SheetContent side={side}>
        <SheetHeader>
          <SheetTitle>
            {title}
          </SheetTitle>
          <SheetDescription>
            POST /v1/chat/completions · 1.42 s
          </SheetDescription>
        </SheetHeader>
        <div className="grid gap-3 px-4 py-6 text-sm">
          <div className="flex justify-between">
            <span>Model</span>
            <span>gpt-4.1</span>
          </div>
          <div className="flex justify-between">
            <span>Input tokens</span>
            <span>1,284</span>
          </div>
          <div className="flex justify-between">
            <span>Cost</span>
            <span>$0.0042</span>
          </div>
        </div>
        <SheetFooter>
          <SheetClose
            className="rounded-md px-3 py-2 shadow-(--custom-shadow)"
          >
            Close
          </SheetClose>
        </SheetFooter>
      </SheetContent>
    </Sheet>
  );
}
```
