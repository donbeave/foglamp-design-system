## API and props

The table lists values exported from `@tailrocks/framerock/ui/sheet`. The declared type comes from the component source.

| Export | Declared props or type | Role |
| --- | --- | --- |
| `Sheet` | `SheetPrimitive.Root.Props` | Dialog-based side panel root. |
| `SheetClose` | `SheetPrimitive.Close.Props` | Control that closes the sheet. |
| `SheetContent` | `SheetPrimitive.Popup.Props & { side?: "top" \| "right" \| "bottom" \| "left"; variant?: "default" \| "floating"; showCloseButton?: boolean; }` | Side panel popup with selected edge and treatment. |
| `SheetDescription` | `SheetPrimitive.Description.Props` | Descriptive text for the associated content. |
| `SheetFooter` | `React.ComponentProps<"div">` | Footer slot for actions or supporting content. |
| `SheetHeader` | `React.ComponentProps<"div">` | Header slot for title and supporting content. |
| `SheetTitle` | `SheetPrimitive.Title.Props` | Title text for the associated content. |
| `SheetTrigger` | `SheetPrimitive.Trigger.Props` | Opens or toggles the associated popup or panel. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `SheetContent.side` | `top \| right \| bottom \| left` | Defaults to `right`. |
| `SheetContent.variant` | `default \| floating` | Defaults to `default`. |
| `SheetContent.showCloseButton` | `boolean` | Defaults to `true`. |

## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { useState } from "react";

import { Sheet, SheetTrigger, SheetContent, SheetHeader, SheetTitle, SheetDescription, SheetFooter, SheetClose } from "@tailrocks/framerock/ui/sheet";

type Args = { side: 'right' };

function SheetStory({ args }: { args: Args }) {

  return <div className="flex min-h-24 w-full items-center justify-center p-4"><Sheet><SheetTrigger className="rounded-md bg-primary px-3 py-2 text-primary-foreground">Inspect trace</SheetTrigger><SheetContent side={args.side}><SheetHeader><SheetTitle>Trace details</SheetTitle><SheetDescription>POST /v1/chat/completions · 1.42 s</SheetDescription></SheetHeader><div className="grid gap-3 py-6 text-sm"><div className="flex justify-between"><span>Model</span><span>gpt-4.1</span></div><div className="flex justify-between"><span>Input tokens</span><span>1,284</span></div><div className="flex justify-between"><span>Cost</span><span>$0.0042</span></div></div></SheetContent><SheetFooter><SheetClose className="rounded-md px-3 py-2 shadow-(--custom-shadow)">Close</SheetClose></SheetFooter></Sheet></div>;
}
```

## Registry item

The story panel resolves this component as registry item `ui-sheet`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-sheet.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-sheet.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@tailrocks/framerock/ui/sheet`. The workspace declares `@tailrocks/framerock` as a package; these docs do not claim npm publication.
