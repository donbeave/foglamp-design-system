# Scroll Area

Scroll container and scrollbar pair backed by Base UI. The scrollbar defaults to vertical orientation.

## Live preview

<story.WithControl />

## API and props

The table lists values exported from `@foglamp/design-system/ui/scroll-area`. The declared type comes from the component source.

| Export | Declared props or type | Role |
| --- | --- | --- |
| `ScrollArea` | `ScrollAreaPrimitive.Root.Props` | Scroll container root. |
| `ScrollBar` | `ScrollAreaPrimitive.Scrollbar.Props` | Scrollbar for the scroll area. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `ScrollBar.orientation` | `vertical \| horizontal` | Defaults to `vertical`. |

## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { useState } from "react";

import { ScrollArea, ScrollBar } from "@foglamp/design-system/ui/scroll-area";

type Args = { variant: 'vertical' };

function ScrollAreaStory({ args }: { args: Args }) {

  return <div className="flex min-h-24 w-full items-center justify-center p-4"><ScrollArea className="h-48 w-full max-w-sm rounded-md shadow-(--custom-shadow)"><div className="space-y-3 p-4">{Array.from({length: 12}, (_,i) => <div key={i} className="flex justify-between border-b pb-2 text-sm"><span>trace_{String(i+1).padStart(3,"0")} · generation</span><span className="text-muted-foreground">{120+i*17} ms</span></div>)}</div><ScrollBar orientation="vertical" /></ScrollArea></div>;
}
```

## Registry item

The story panel resolves this component as registry item `ui-scroll-area`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-scroll-area.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-scroll-area.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@foglamp/design-system/ui/scroll-area`. The workspace declares `@foglamp/design-system` as a package; these docs do not claim npm publication.
