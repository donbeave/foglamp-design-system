## API and props


| Export | Declared props or type | Role |
| --- | --- | --- |
| `ButtonGroup` | `React.ComponentProps<"div"> & VariantProps<typeof buttonGroupVariants>` | Group root with horizontal or vertical orientation. |
| `ButtonGroupSeparator` | `React.ComponentProps<typeof Separator>` | Visual or semantic divider. |
| `ButtonGroupText` | `useRender.ComponentProps<"div">` | Text slot aligned with grouped controls. |
| `buttonGroupVariants` | `Class variance recipe` | Exports the button group class recipe. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `ButtonGroup.orientation` | `horizontal \| vertical` | Group direction. |

## Usage

```tsx
import { Button } from "@tailrocks/framerock/ui/button";
import {
  ButtonGroup,
  ButtonGroupText,
  ButtonGroupSeparator,
} from "@tailrocks/framerock/ui/button-group";

export function ButtonGroupExample({
  orientation = 'horizontal',
}: {
  orientation?: 'horizontal' | 'vertical';
} = {}) {
  return (
    <ButtonGroup orientation={orientation} aria-label="Time range">
      <Button variant="outline" size="sm">1h</Button>
      <Button variant="outline" size="sm">24h</Button>
      <Button variant="secondary" size="sm">7d</Button>
      <ButtonGroupSeparator />
      <ButtonGroupText>UTC</ButtonGroupText>
    </ButtonGroup>
  );
}
```
