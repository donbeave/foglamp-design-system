# Select

Base UI selection control with popup positioning and scroll controls. When items is omitted, the root collects labels from nested SelectItem children.

## Live preview

<story.WithControl />

## API and props

The table lists values exported from `@foglamp/design-system/ui/select`. The declared type comes from the component source.

| Export | Declared props or type | Role |
| --- | --- | --- |
| `Select` | `SelectPrimitive.Root.Props<Value, Multiple>` | Selection root that collects nested labels when items are omitted. |
| `SelectContent` | `SelectPrimitive.Popup.Props & Pick< SelectPrimitive.Positioner.Props, "align" \| "alignOffset" \| "side" \| "sideOffset" \| "alignItemWithTrigger" >` | Positioned select popup. |
| `SelectGroup` | `SelectPrimitive.Group.Props` | Groups related entries. |
| `SelectItem` | `SelectPrimitive.Item.Props` | One selectable option in the select list. |
| `SelectLabel` | `SelectPrimitive.GroupLabel.Props` | Label for the associated control or group. |
| `SelectScrollDownButton` | `React.ComponentProps<typeof SelectPrimitive.ScrollDownArrow>` | Control that scrolls the select popup toward later items. |
| `SelectScrollUpButton` | `React.ComponentProps<typeof SelectPrimitive.ScrollUpArrow>` | Control that scrolls the select popup toward earlier items. |
| `SelectSeparator` | `SelectPrimitive.Separator.Props` | Visual or semantic divider. |
| `SelectTrigger` | `SelectPrimitive.Trigger.Props & { size?: "sm" \| "default"; }` | Control that opens the select popup. |
| `SelectValue` | `SelectPrimitive.Value.Props` | Displays the selected select value. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `Select.items` | `Base UI select items` | Optional item mapping or list. If omitted, the root collects `SelectItem` labels from nested children. |
| `SelectTrigger.size` | `sm \| default` | Defaults to `default`. |
| `SelectContent.side` | `Base UI positioner side` | Defaults to `bottom`. |
| `SelectContent.sideOffset` | `number` | Defaults to `4`. |
| `SelectContent.align` | `Base UI positioner alignment` | Defaults to `center`. |
| `SelectContent.alignOffset` | `number` | Defaults to `0`. |
| `SelectContent.alignItemWithTrigger` | `boolean` | Defaults to `false`. |
| `SelectItem.label` | `React.ReactNode` | Explicit item label used by child-label collection. |

## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { useState } from "react";

import { Select, SelectTrigger, SelectValue, SelectContent, SelectGroup, SelectLabel, SelectItem, SelectSeparator } from "@foglamp/design-system/ui/select";

import { Label } from "@foglamp/design-system/ui/label";

type Args = { variant: 'gpt-4.1' };

function SelectStory({ args }: { args: Args }) {
  const [model, setModel] = useState("gpt-4.1");
  return <div className="flex min-h-24 w-full items-center justify-center p-4"><div className="grid max-w-xs gap-2"><Label>Model</Label><Select value={model} onValueChange={value => value && setModel(value)}><SelectTrigger><SelectValue placeholder="Choose a model" /></SelectTrigger><SelectContent><SelectGroup><SelectLabel>OpenAI</SelectLabel><SelectItem value="gpt-4.1">GPT-4.1</SelectItem><SelectItem value="o4-mini">o4-mini</SelectItem></SelectGroup><SelectSeparator /><SelectGroup><SelectLabel>Anthropic</SelectLabel><SelectItem value="claude-sonnet">Claude Sonnet</SelectItem></SelectGroup></SelectContent></Select><p className="text-xs text-muted-foreground">Selected: {model}</p></div></div>;
}
```

## Registry item

The story panel resolves this component as registry item `ui-select`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-select.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-select.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@foglamp/design-system/ui/select`. The workspace declares `@foglamp/design-system` as a package; these docs do not claim npm publication.
