## API and props


| Export | Declared props or type | Role |
| --- | --- | --- |
| `Badge` | `useRender.ComponentProps<"span"> & VariantProps<typeof badgeVariants>` | Status label with variant and size options. |
| `badgeVariants` | `Class variance recipe` | Exports the badge class recipe. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `Badge.variant` | `default \| secondary \| destructive \| green \| blue \| amber \| orange \| emerald \| rose \| red \| violet \| fuchsia \| sky \| outline` | Defaults to `default`. |
| `Badge.size` | `sm \| md \| lg` | Defaults to `md`. |

## Usage

```tsx
import { Badge } from "@tailrocks/framerock/ui/badge";

export function BadgeExample({
  variant = 'default',
  size = 'md',
}: {
  variant?: 'default' | 'secondary' | 'destructive' | 'green' | 'blue' | 'amber' | 'outline';
  size?: 'sm' | 'md' | 'lg';
} = {}) {
  return (
    <div className="flex flex-wrap items-center gap-3">
      <Badge variant={variant} size={size}>Production</Badge>
      <Badge variant="green">Healthy</Badge>
      <Badge variant="amber">Latency</Badge>
      <Badge variant="outline">v2.8.1</Badge>
    </div>
  );
}
```
