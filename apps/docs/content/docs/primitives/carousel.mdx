# Carousel

Embla-backed, axis-aware carousel with content, item, previous, and next controls. The root accepts Embla options and plugins and can expose its API through setApi.

## API and props

The table lists values exported from `@tailrocks/framerock/ui/carousel`. The declared type comes from the component source.

| Export | Declared props or type | Role |
| --- | --- | --- |
| `Carousel` | `React.ComponentProps<"div"> & CarouselProps` | Embla carousel root and context provider. |
| `CarouselApi` | `type UseEmblaCarouselType[1]` | Embla API type exposed by the carousel module. |
| `CarouselContent` | `React.ComponentProps<"div">` | Contains the associated popup or panel content. |
| `CarouselItem` | `React.ComponentProps<"div">` | One selectable or repeated entry. |
| `CarouselNext` | `React.ComponentProps<typeof Button>` | Next-item or next-page control. |
| `CarouselPrevious` | `React.ComponentProps<typeof Button>` | Previous-item or previous-page control. |
| `useCarousel` | `Exported component or value` | Returns the carousel API and navigation state. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `Carousel.orientation` | `horizontal \| vertical` | Defaults to `horizontal`. |
| `Carousel.opts` | `Embla options` | Passed to `useEmblaCarousel`. |
| `Carousel.plugins` | `Embla plugins` | Passed to `useEmblaCarousel`. |
| `Carousel.setApi` | `(api) => void` | Receives the Embla API after initialization. |

## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { Carousel, CarouselContent, CarouselItem, CarouselPrevious, CarouselNext } from '@tailrocks/framerock/ui/carousel';

function CarouselExample({ orientation = 'horizontal' }: { orientation?: 'horizontal' | 'vertical' }) { return <Carousel orientation={orientation} className="w-full max-w-lg"><CarouselContent>{['Latency distribution', 'Token usage', 'Cost by model'].map((title, index) => <CarouselItem key={title} className="md:basis-1/2"><div className="rounded-lg bg-muted p-6"><p className="text-xs text-muted-foreground">METRIC 0{index + 1}</p><h3 className="mt-2 font-medium">{title}</h3><p className="mt-1 text-sm text-muted-foreground">{index === 0 ? 'p95 · 680 ms' : index === 1 ? '14.2k tokens' : '$0.084 / run'}</p></div></CarouselItem>)}</CarouselContent><div className="mt-4 flex justify-end gap-2"><CarouselPrevious className="static translate-y-0" /><CarouselNext className="static translate-y-0" /></div></Carousel>; }
```

## Registry item

The story panel resolves this component as registry item `ui-carousel`. When the portal runs locally at `http://localhost:3000`, the JSON URL is `http://localhost:3000/r/ui-carousel.json`. The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-carousel.json`. This URL is local to the running portal, not a public registry address.

The package import path is `@tailrocks/framerock/ui/carousel`. The workspace declares `@tailrocks/framerock` as a package; these docs do not claim npm publication.
