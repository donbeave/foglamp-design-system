## API and props


| Export | Declared props or type | Role |
| --- | --- | --- |
| `Carousel` | `React.ComponentProps<"div"> & CarouselProps` | Embla carousel root and context provider. |
| `CarouselApi` | `type UseEmblaCarouselType[1]` | Embla API type exposed by the carousel module. |
| `CarouselContent` | `React.ComponentProps<"div">` | Contains the associated popup or panel content. |
| `CarouselItem` | `React.ComponentProps<"div">` | One selectable or repeated entry. |
| `CarouselNext` | `React.ComponentProps<typeof Button>` | Next-item or next-page control. |
| `CarouselPrevious` | `React.ComponentProps<typeof Button>` | Previous-item or previous-page control. |
| `useCarousel` | `Exported component or value` | Returns the carousel API and navigation state. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `Carousel.orientation` | `horizontal \| vertical` | Defaults to `horizontal`. |
| `Carousel.opts` | `Embla options` | Passed to `useEmblaCarousel`. |
| `Carousel.plugins` | `Embla plugins` | Passed to `useEmblaCarousel`. |
| `Carousel.setApi` | `(api) => void` | Receives the Embla API after initialization. |

## Usage

```tsx
import {
  Carousel,
  CarouselContent,
  CarouselItem,
  CarouselPrevious,
  CarouselNext,
} from "@tailrocks/framerock/ui/carousel";

export function CarouselExample({
  orientation = 'horizontal',
}: {
  orientation?: 'horizontal' | 'vertical';
} = {}) {
  return (
    <Carousel orientation={orientation} className="w-full max-w-lg">
      <CarouselContent>
        {['Latency distribution', 'Token usage', 'Cost by model'].map((title, index) => (
            <CarouselItem key={title} className="md:basis-1/2">
              <div className="rounded-lg bg-muted p-6">
                <p className="text-xs text-muted-foreground">
                  METRIC 0
                  {index + 1}
                </p>
                <h3 className="mt-2 font-medium">
                  {title}
                </h3>
                <p className="mt-1 text-sm text-muted-foreground">
                  {index === 0 ? 'p95 · 680 ms' : index === 1 ? '14.2k tokens' : '$0.084 / run'}
                </p>
              </div>
            </CarouselItem>
        ))}
      </CarouselContent>
      <div className="mt-4 flex justify-end gap-2">
        <CarouselPrevious className="static translate-y-0" />
        <CarouselNext className="static translate-y-0" />
      </div>
    </Carousel>
  );
}
```
