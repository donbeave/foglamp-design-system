## API and props


| Export | Declared props or type | Role |
| --- | --- | --- |
| `Item` | `useRender.ComponentProps<"div"> & VariantProps<typeof itemVariants>` | Row container with variant and size options. |
| `ItemActions` | `React.ComponentProps<"div">` | Action slot inside an item row. |
| `ItemContent` | `React.ComponentProps<"div">` | Main content slot inside an item row. |
| `ItemDescription` | `React.ComponentProps<"p">` | Descriptive text for the associated content. |
| `ItemFooter` | `React.ComponentProps<"div">` | Footer slot inside an item row. |
| `ItemGroup` | `React.ComponentProps<"div">` | Groups item rows. |
| `ItemHeader` | `React.ComponentProps<"div">` | Header slot inside an item row. |
| `ItemMedia` | `React.ComponentProps<"div"> & VariantProps<typeof itemMediaVariants>` | Media slot with default, icon, or image treatment. |
| `ItemSeparator` | `React.ComponentProps<typeof Separator>` | Separator between item rows. |
| `ItemTitle` | `React.ComponentProps<"div">` | Title text for the associated content. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `Item.variant` | `default \| outline \| muted` | Defaults to `default`. |
| `Item.size` | `default \| sm \| xs` | Defaults to `default`. |
| `ItemMedia.variant` | `default \| icon \| image` | Defaults to `default`. |

## Usage

```tsx
import {
  Item,
  ItemGroup,
  ItemMedia,
  ItemContent,
  ItemTitle,
  ItemDescription,
  ItemActions,
} from "@tailrocks/framerock/ui/item";

export function ItemExample({
  title = "Production deployment",
  meta = "Model evaluation completed · 2 minutes ago",
  variant = "outline",
}: {
  title?: string;
  meta?: string;
  variant?: "default" | "outline" | "muted";
} = {}) {
  return (
    <ItemGroup>
      <Item variant={variant}>
        <ItemMedia variant="icon">✦</ItemMedia>
        <ItemContent>
          <ItemTitle>
            {title}
          </ItemTitle>
          <ItemDescription>
            {meta}
          </ItemDescription>
        </ItemContent>
        <ItemActions>
          <button type="button" className="text-sm text-primary">
            Review
          </button>
        </ItemActions>
      </Item>
    </ItemGroup>
  );
}
```
