## API and props

The table lists values exported from `@tailrocks/framerock/ui/toggle-group`. The declared type comes from the component source.

| Export | Declared props or type | Role |
| --- | --- | --- |
| `ToggleGroup` | `ToggleGroupPrimitive.Props & VariantProps<typeof toggleVariants> & { spacing?: number; orientation?: "horizontal" \| "vertical"; }` | Toggle group with shared variant, size, orientation, and spacing. |
| `ToggleGroupItem` | `TogglePrimitive.Props & VariantProps<typeof toggleVariants>` | Toggle button that shares the group state and options. |

## Additional props

| Prop | Type | Description |
| --- | --- | --- |
| `ToggleGroup.variant` | `Toggle variant` | Shared toggle treatment. |
| `ToggleGroup.size` | `Toggle size` | Shared toggle dimensions. |
| `ToggleGroup.spacing` | `number` | Defaults to `0`. |
| `ToggleGroup.orientation` | `horizontal \| vertical` | Defaults to `horizontal`. |

## Example

The example is the portal story fixture without its story registration. It uses the same package imports as the live preview.

```tsx
import { useState } from "react";

import { ToggleGroup, ToggleGroupItem } from "@tailrocks/framerock/ui/toggle-group";

type Args = { period: '24h' };

function ToggleGroupStory({ args }: { args: Args }) {
  const [period, setPeriod] = useState("24h");
  return <div className="flex min-h-24 w-full items-center justify-center p-4"><div className="grid gap-3"><ToggleGroup defaultValue={["24h"]} aria-label="Time period"><ToggleGroupItem value="1h" aria-label="Last hour">1h</ToggleGroupItem><ToggleGroupItem value="24h" aria-label="Last day">24h</ToggleGroupItem><ToggleGroupItem value="7d" aria-label="Last week">7d</ToggleGroupItem></ToggleGroup><p className="text-xs text-muted-foreground">Showing activity for {period}.</p></div></div>;
}
```

The matching local install command is `npx shadcn@latest add http://localhost:3000/r/ui-toggle-group.json`. This URL is local to the running portal, not a public registry address.
